## 1. 配色

全站不强求完全相同的页面底色。Home/About 使用青瓷色系，Projects 使用石墨黑白灰，Notes 与 Contact 保留各自的章节气质；统一感由排版、内容宽度、导航、页脚和过渡节奏承担。

### 章节画布策略

| 章节 | 浅色画布 | 深色画布 | 定位 |
|------|------|------|------|
| Home / About | `#F7F4EC` | `#111815` | 青瓷纸面 |
| Projects | `#FFFFFF` | `#0D1117` | 冷白涂布纸 / 工程图版 |
| Notes | `#E5EEF5` | `#111820` | 日光工程手稿 / 石墨深海 |
| Contact | `#F5F0E8` | `#0A0A0A` | 克制的黑白收束 |

> 画布允许受控差异，但同处纸白与墨黑两个明度家族；页面切换使用 300ms 颜色过渡，让变化表现为章节翻页，而不是界面断裂。减少动态偏好下直接切换。
>
> About、Projects 与 Notes 共用 `section-page-frame`：基础、`sm`、`md` 三档标题顶距分别为 5rem、6rem、8rem；共享标题行最小高度为 2.5rem。固定导航只负责覆盖页面背景，标准章节标题与 About 切换按钮不得进入导航命中区，且在三档宽度保持同一标题基线。

## 2. 字体

策略：**西文用 Web Font，中文用系统字体栈**（中文字体体积大，不适合 Web 加载）。

### 2.1 正文字体（Sans-serif）

| 平台 | 西文 | 中文 | 后备 |
|------|------|------|------|
| **macOS / iOS** | Inter (Web Font) | 苹方 `PingFang SC` | 系统 `system-ui` |
| **Windows** | Inter (Web Font) | 微软雅黑 `Microsoft YaHei` | 思源黑体 `Noto Sans SC` |
| **Android** | Inter (Web Font) | 思源黑体 `Noto Sans SC` | `sans-serif` |
| **fallback** | — | — | `sans-serif` |

CSS 栈：
```
font-family: 'Inter', -apple-system, 'PingFang SC', 'Microsoft YaHei', 'Noto Sans SC', sans-serif;
```

### 2.2 代码字体（Mono）

| 字体 | 平台 |
|------|------|
| JetBrains Mono (Web Font) | 所有平台优先加载 |
| Fira Code | 后备 |
| `Menlo`, `Consolas` | 系统字体后备 |
| `monospace` | 最终后备 |

```
font-family: 'JetBrains Mono', 'Fira Code', Menlo, Consolas, monospace;
```

### 2.3 字号阶梯（建议）

| 层级 | 字号 | 行高 | 用途 |
|------|------|------|------|
| H1 | 48px / 3rem | 1.15 | 页面主标题 |
| H2 | 36px / 2.25rem | 1.2 | 区块标题 |
| H3 | 28px / 1.75rem | 1.25 | 子标题 |
| Body | 16px / 1rem | 1.6 | 正文 |
| Small | 14px / 0.875rem | 1.5 | 辅助信息 |
| Caption | 12px / 0.75rem | 1.4 | 注释/标签 |

> 响应式缩放：移动端所有字号 × 0.875

### 2.4 Markdown 文档排版

Markdown 阅读区采用“窄正文、宽技术块”的双层宽度策略：

- 标题、段落、列表、引用和分隔线限制为 `65ch`，保持长文可读性。
- 代码块、表格、函数图像和显示公式可以使用笔记内容列的完整宽度，避免技术内容被迫换行或横向压缩。
- 页面级字号阶梯用于导航、页面标题与区块标题；Markdown 正文保留 Typography 的紧凑层级与节奏，正文为 `16px / 1.75`。

笔记的 frontmatter `title` 是站内文档标题。Markdown 文件允许保留同名首个 H1，以便脱离站点后仍是完整文档；站内渲染时只显示一次，并保留标题锚点。

样式职责固定如下：Typography 负责标准 Markdown 元素，`index.css` 负责主题变量与少量受控例外，代码块和函数图像通过 `not-prose` 独立渲染。组件内不再注入局部 `<style>`。

### 2.5 笔记目录交互

笔记目录遵循文件树而不是手风琴菜单的状态模型：

- 目录主按钮只负责展开或收起；独立的文档按钮用于打开目录概览，避免一次点击触发两个相互覆盖的动作。
- 打开笔记时只补齐它的祖先路径，不清除读者手动展开的其他分支；目录初始保持全部收起。
- 目录使用约 180ms 的高度、透明度与轻微位移反馈；收起动画结束后卸载子树，不使用固定 `max-height` 裁切长目录。
- 动效只呈现展开状态，不参与决定展开状态；快速反向操作取消旧的退场计时，并遵循系统 `prefers-reduced-motion`。
- 搜索区始终固定在目录滚动区域顶部；移动端固定在全局导航下方，深层目录只滚动内容，不带走搜索入口。
- 以下划线开头的目录视为内部内容，不进入公开目录或搜索；缺少 `_index.md` 的目录使用可读回退标题。
- 目录按稳定的路径名称进行自然排序，显示标题不参与排序，避免系统 locale 改变分类顺序。

## 3. 间距与布局

### 3.1 基础间距单位（已确认：均衡）

采用 **8px 栅格系统**（Tailwind 默认 `0.25rem = 4px`，偶数倍取 8px 的倍数）。

| Tailwind 类 | 值 | 用途 |
|-------------|-----|------|
| `space-2` | 8px | 内元素间距（图标与文字、列表项） |
| `space-3` | 12px | 紧凑间距 |
| `space-4` | 16px | 卡片内边距、段落间距 |
| `space-5` | 20px | 组件间距 |
| `space-6` | 24px | 中等间距 |
| `space-8` | 32px | 区块间距 |
| `space-12` | 48px | 大区块间距 |
| `space-16` | 64px | 页面级留白 |

### 3.2 内容最大宽度

| 断点 | 值 | 用途 |
|------|-----|------|
| `max-w-prose` | 65ch | 正文阅读区（最佳可读性） |
| `max-w-2xl` | ~672px | 卡片/表单 |
| `max-w-4xl` | ~896px | 页面容器（窄屏） |
| `max-w-6xl` | ~1152px | 页面容器（宽屏） |

### 3.3 响应式断点

| 断点 | 值 | 设备 |
|------|-----|------|
| `sm` | 640px | 手机横屏 |
| `md` | 768px | 平板竖屏 |
| `lg` | 1024px | 平板横屏 / 小笔记本 |
| `xl` | 1280px | 桌面 |
| `2xl` | 1536px | 大屏 |

### 3.4 页面留白策略

- PC：左右对称留白，内容居中
- 移动端：左右各 16px padding（`sm:px-4`）
- 上下间距：区块之间 `py-16`（64px），移动端 `py-10`

## 4. 组件风格（已确认）

### 4.1 边框半径

| 用途 | 值 | 类 |
|------|-----|-----|
| 按钮 | `12px` | `rounded-xl` |
| 输入框/标签 | `8px` | `rounded-lg` |
| 卡片 | `12px` | `rounded-xl` |
| 模态框/弹窗 | `12px` | `rounded-xl` |

> 按钮和卡片用大圆角，输入框用微圆角，形成层级区分。

### 4.2 阴影与边框

原则：**边框为主、阴影为辅**，既有质感又不飘。

| 层级 | 方案 |
|------|------|
| 卡片 | 1px 浅色边框 + `shadow-sm`（`0 1px 2px rgba(0,0,0,0.05)`） |
| 悬浮元素 | hover 时边框颜色加深 + 微上移 |
| 弹窗/下拉 | 1px 边框 + `shadow-md` |

### 4.3 按钮

| 状态 | 样式 |
|------|------|
| 主要按钮 | 强调色背景 + 白字 + 大圆角 |
| 次要按钮 | 透明背景 + 强调色文字 + 细边框 + 大圆角 |
| 禁用 | 50% 透明度 + `cursor-not-allowed` |

### 4.4 卡片

- 1px 浅色边框 + 微阴影 `shadow-sm`
- 背景与页面背景同色或深一档
- hover 时边框加深 + 微上移 `translateY(-2px)`

### 4.5 项目贡献图

- GitHub 贡献数据在构建阶段生成快照，Projects 页面只消费规范化的日期、次数和等级；前端不携带令牌，也不嵌入第三方贡献图图片。
- 日历属于页面排版而非独立卡片：使用上下细分隔线、Projects 黑白灰色阶、站内字号和留白，避免复制 GitHub 小组件的外观。
- 桌面端在可用宽度中呈现完整年度；移动端保持格子可读尺寸、横向滚动并默认定位到最新日期，不缩小整张图。
- 单格只提供轻微悬停反馈，周列以短促错峰淡入；遵循 `prefers-reduced-motion`，不使用持续动画。
- 构建刷新失败时保留仓库中的最后一次有效快照，避免第三方状态导致项目页空白或部署失败。

## 5. 动效（已确认：柔和轻快之间）

原则：**克制、流畅、不炫技**。全部采用 200ms，介于轻快（150ms）和柔和（300ms）之间。

| 场景 | 时长 | 缓动 |
|------|------|------|
| 按钮 hover | 200ms | `ease-out` |
| 卡片 hover | 200ms | `ease-out` + 上移 2px |
| 页面切换 | 200ms | `ease-in-out` |
| 展开/折叠 | 200ms | `ease-out` |

> 遵循系统 `prefers-reduced-motion`：用户关闭动效时全部禁用。

## 6. 暗色模式

已实现全站明暗模式。每个章节独立校准画布、局部表面、正文、次级文字和强调色，不由浅色值机械反相；不同章节的底色限制在一致的纸白或墨黑明度家族中。切换结果持久化到本地设置，并遵循系统的减少动态偏好。
