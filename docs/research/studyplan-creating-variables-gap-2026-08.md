## 当前仍有价值的缺口

### 注释

指定页面正式介绍了 `//` 与 `/* ... */`。当前笔记示例已经使用 `//`，但尚未解释其语法和用途，因此注释是这次对照中最明确的缺口。

注释与对象或变量没有语义依赖，也不属于表达式。它是源代码的词法结构和可读性工具。当前阶段可以先把它作为“对象、类型与变量”章节中的收尾补篇，让读者在继续阅读大量示例之前知道哪些文本是代码、哪些文本只写给人看；未来形成更完整的“源文件、语句与程序结构”章节时，再考虑整体迁移。

C++ 工作草案的 [Comments](https://eel.is/c%2B%2Bdraft/lex.comment) 规定两种注释形式及其词法行为。正文还应超越语法，说明好的注释用于补充代码不能直接表达的意图、约束和原因，而不是逐字复述代码。[Google C++ Style Guide 的 Comments](https://google.github.io/styleguide/cppguide.html#Comments) 也强调先用清晰的名称和结构让代码自说明，并避免陈述显而易见的行为。

### 从另一个对象初始化

页面说明可以用已有变量的值初始化新变量，并指出两个变量之后可以独立更新。当前重构后的笔记虽已分别解释对象、初始化和赋值，但没有保留这一关系的直接示例。适合在“初始化”小节内补一段：初始化器读取源对象当时的值来建立新对象；后续修改任一对象不会自动同步另一个对象。

这不是完整的 C++“拷贝语义”教学。类的复制构造、浅拷贝与深拷贝等内容应在类和值语义之后展开。
