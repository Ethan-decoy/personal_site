# Engineering Skills

工程类技能用于把一个想法从模糊计划推进到可审查的代码，同时照顾 issue tracker、领域语言、测试反馈和架构复杂度。

## 主线

```txt
grill-with-docs -> to-prd -> to-issues -> implement -> code-review
```

这条链路适合“要做一个相对完整的改动”。如果只是临时调试、做原型、研究资料或处理冲突，可以直接使用对应的独立技能。
