# research

来源：[skills/engineering/research](https://github.com/mattpocock/skills/tree/main/skills/engineering/research)

## 快速安装

```bash
npx skills add mattpocock/skills --skill=research
npx skills update research
```

## 它解决什么

`research` 通过阅读拥有答案的一手来源来回答问题，并在仓库里留下带引用的 Markdown 文件。

它不依赖二手文章，不把“别人总结的总结”当事实。优先阅读官方文档、源代码、标准、规范或第一方 API。

## 何时使用

当下一步是“查清楚某件事”时使用：

- API 到底如何表现。
- 某个规范真正说了什么。
- 某个技术主张是否成立。
- 不想让当前主会话陷入大量阅读。

如果要通过访谈磨计划，用 `grilling`。如果要用代码探索设计，用 `prototype`。

## 工作方式

阅读工作由后台 Agent 承担。它追踪每个结论到一手来源，然后把结果写成一份可反应、可引用的文档。

研究是可以委托的阅读劳动，不是把判断也外包出去。你拿回来的应该是一份带来源的材料，而不是无出处的结论。

## 记忆点

高质量研究的关键不是“读得多”，而是读对拥有答案的来源。
