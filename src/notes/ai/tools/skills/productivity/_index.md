# Productivity Skills

## 技能索引

- [grill-me](./grill-me.md)：只做计划拷问，不写文档。
- [grilling](./grilling.md)：拷问原语，供其他技能复用。
- [handoff](./handoff.md)：压缩长会话，交给新 Agent。
- [teach](./teach.md)：长期学习工作区。
- [writing-great-skills](./writing-great-skills.md)：写好技能的元参考。
