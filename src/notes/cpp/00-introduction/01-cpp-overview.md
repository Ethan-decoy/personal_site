# C++ 语言概述

**C++ 诞生于一个很实际的想法：保留 C 语言贴近机器、运行高效的特点，同时为大型程序提供更好的组织和抽象能力。**

C++ 的故事始于 1979 年。当时，Bjarne Stroustrup 在贝尔实验室工作。他欣赏 Simula 将复杂系统组织成清晰概念的方式，同时也需要 C 语言贴近硬件、运行高效并适合系统编程的特点。于是，他开始尝试把两者结合起来。

**如果说 C 让程序拥有了可以直接触碰机器的手脚，那么 C++ 所做的，就是在保留这些手脚的同时，为它创造出一套可以拿起、组合和复用的工具。**

这项工作最初叫作“C with Classes”，也就是“带类的 C”。1983 年，这门语言正式改名为 C++。名称中的 `++` 来自 C 的递增运算符，表达它是在 C 基础上的继续演进。

1985 年，第一个商业实现与《The C++ Programming Language》第一版发布；1998 年，C++ 有了第一版 ISO 标准。此后，C++03、C++11、C++14、C++17、C++20 和 C++23 持续推动语言演进，其中 C++11 是现代 C++ 的重要转折点。

今天的 C++ 早已不只是“给 C 加上类”，也不要求所有程序采用同一种组织方式。我们既可以直接处理内存和硬件资源，也可以把反复出现的细节整理成能够组合和复用的程序部件。这使它常见于操作系统与基础设施、游戏引擎、浏览器、嵌入式系统和高性能计算等领域。

这种自由是 C++ 最有价值、也最需要谨慎对待的地方。**它让程序员拥有很强的控制力，却不会自动保证代码高效或安全。**理解 C++，不仅要知道语法怎样写，还要知道数据何时产生和消失、资源由谁管理、抽象需要付出什么成本，以及哪些行为是语言真正保证的。
