# 面向对象编程（Object-Oriented Programming，OOP）

**就像汽车和飞机由许多各司其职的部件组合而成，面向对象编程也把庞大的程序组织成许多相对独立的对象。**每个对象保存与自己有关的信息，负责自己能够完成的事情，并与其他对象共同构成完整系统。

假设要在程序中模拟一辆汽车。程序不需要真的制造橡胶和钢铁，而是记录一条轮胎的尺寸、胎纹、气压、温度和磨损程度，再描述它在行驶过程中会怎样转动、升温和磨损。**汽车上的四条轮胎看起来相似，却各自保存着不同的信息：其中一条漏气，并不会让另外三条同时漏气。**

轮胎与轮毂组成车轮，车轮与发动机、转向系统和车身共同组成汽车。每个部分只需要做好自己的事情，再通过彼此配合，让整辆汽车运行起来。庞大的程序也可以用相似的方式逐步构建。

面向对象编程是 C++ 支持的一种程序组织方式，并不是 C++ 本身的全部。这里的“对象”用于建立组织复杂系统的直觉；C++ 在语言规则中使用 object 这个术语时，范围还要更广。

**把系统理解为许多保存自身状态、承担相应职责并彼此协作的对象，再由这些对象逐层组合出完整程序——这就是面向对象编程。**
