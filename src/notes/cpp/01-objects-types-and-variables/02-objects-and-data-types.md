# 对象、值与数据类型（Objects, Values, and Data Types）

## C++ 语言中的对象（Object）

在绘图程序中，一个圆可以作为整体接受移动与绘制请求。C++ 语言规则中的对象范围更广：即使一份数据只保存圆 A 中心的横向位置，它也可以是一个对象。

本篇把完整图形缩小为这一份数值，观察对象、值与类型。所有代码片段都放在 `main` 函数体内；它们用于保存和改变位置数值，没有接入绘图界面：

```cpp
double circle_x{20.0};
```

先把这一行的三个组成对应起来：`double` 指定数据类型，`circle_x` 是访问这份数据的名称，`{20.0}` 给出对象创建时的初始值。代码使程序中出现一个 `double` 对象，并让这个名称指代它。对象当前保存的值是 `20.0`。

**这份数值对象具有类型、占用存储，并在程序运行的一段时间内存在。**对象从开始存在到不再存在的时间范围称为生命周期（lifetime）；类型规定它能够表示哪些值，以及程序可以对它进行哪些操作。

## 对象与值（Object and Value）

对象与它当前保存的值不是同一个概念。在前面的声明之后继续执行下面这条赋值语句，可以改变对象保存的值：

```cpp
circle_x = 35.0;
```

> [!IMPORTANT] 对象与当前值的区别
> 这次操作把 `circle_x` 的值从 `20.0` 改成了 `35.0`，名称指代的仍然是原来的对象。对象身份回答“这是哪一个对象”，值回答“这个对象当前保存了什么”。对象可以继续存在，而它的值在允许修改时发生变化。

下面这个独立示例中，两个对象具有相同的类型和值，却仍然彼此独立：

```cpp
double circle_x{20.0};
double other_circle_x{20.0};

circle_x = 35.0;
```

最后，`circle_x` 保存 `35.0`，`other_circle_x` 仍然保存 `20.0`。相同的数值不会把两个对象合并为同一个对象。这里分别保存两个圆的横向位置，没有建立联动更新；改变其中一份数值，不会自动改变另一份，也不会自动执行绘制操作。

## 数据类型（Data Type）

同样是保存数据，图形数量、中心位置、选中状态和文本需要的值与操作并不相同。数据类型（data type，通常简称 type）规定对象能够表示哪些值，以及程序可以对它进行哪些操作。

回到最初的代码：

```cpp
double circle_x{20.0};
```

`double` 是 `circle_x` 的类型，规定它按照浮点类型的规则表示和处理数值。将值从 `20.0` 改为 `35.0` 不会把对象变成其他类型。**对象的值可以发生变化，但对象的类型在其生命周期内保持不变。**

回看当前例子，已经可以分别判断：名称指向哪一个对象、它当前保存什么值、类型允许怎样使用它。

当前例子只用到 `double`。下面按信息用途列出本章会用到的几组 C++ 内建类型，供定位：

| 表达的信息 | 常用类型 |
| --- | --- |
| 逻辑状态 | `bool` |
| 整数 | `short`、`int`、`long`、`long long` 及其无符号形式 |
| 字符与编码单元 | `char`、`signed char`、`unsigned char` |
| 浮点数 | `float`、`double`、`long double` |

这些分组只描述本章将要解决的问题，不是 C++ 类型系统的完整分类。

## 对象与存储

对象、值与类型说明了当前代码中的关系。要继续理解数值类型能够表示多大的范围，还需要知道存储的计量单位。

程序运行期间，对象在 C++ 抽象机（abstract machine）的存储中存在。这里的存储是语言用来规定对象行为的模型，不是对某块物理硬件位置的直接承诺。

> [!NOTE]
> **对象占用存储，不等于源代码中的每个对象都必须永久对应主内存里一块固定可见的区域。**语言首先规定程序应当表现出的结果，具体实现只需符合这些规则。对象与实际存储位置之间更精细的关系，需要在程序开始观察对象地址时才能完整建立。

## 比特与字节（Bits and Bytes）

二进制（binary）表示用 `0` 和 `1` 组成不同的信息。每一位称为比特（bit），只能取这两个值；多位放在一起，就能区分更多组合。例如，两位可以组成 `00`、`01`、`10`、`11` 四种比特组合（bit pattern）。

现代通用计算机通常将连续的 8 bits 组织成一个字节（byte）。每一位有两种选择，所以一个 8-bit byte 可以形成 $2^8=256$ 种不同的比特组合。

**一个 C++ byte 至少包含 8 bits；C++ 使用 byte 作为衡量对象存储大小的基本单位，但没有规定它在所有实现中都必须恰好包含 8 bits。**8-bit byte 是当前主流通用平台采用的实现。

> [!NOTE]
> 相同的比特组合按不同类型的规则解释，可能具有不同含义。**类型是对象在 C++ 语言模型中的属性，不是普通对象旁边自动保存的一枚运行期标签。**单独取得一段原始 bytes，通常无法只凭这些 bytes 判断它们原本属于 `int`、`double` 还是其他类型；编译器根据源代码中已经建立的类型关系和语言规则，解释和使用对象。
