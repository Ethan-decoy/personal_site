# 对象、值与数据类型（Objects, Values, and Data Types）

## C++ 语言中的对象（Object）

代码片段均写在 `main` 函数体内；注明接续时沿用前面的对象，其余示例各自独立。这些代码只保存和修改数值，没有连接绘图界面。

保存圆 A 的横向位置，可以使用这条声明（declaration）：

```cpp
double circle_x{20.0};
```

执行这条声明时，程序创建一个对象（object），并将初值设为 `20.0`。在对象创建时建立初始状态的过程称为初始化（initialization）。这里由花括号中的数值提供初值，末尾的 `;` 结束声明。

这条声明中的名称、对象、值与类型分别是：

| 概念 | 这条声明中的含义 |
| --- | --- |
| 名称 | `circle_x`，用于访问对象 |
| 对象 | 由这条声明创建、用来保存圆 A 横向位置的那份数值数据 |
| 值（value） | `20.0`，是对象当前保存的内容，这里表示横向位置为 20 |
| 类型 | `double`，规定数值的表示与使用规则 |

## 对象与值（Object and Value）

在前面的声明之后继续执行：

```cpp
circle_x = 35.0;
```

这里的 `=` 表示赋值（assignment）：把右侧的 `35.0` 写入左侧名称所指代的对象。执行后，通过 `circle_x` 访问的仍是原来的对象，它当前保存的值从 `20.0` 改成了 `35.0`。

> [!IMPORTANT] 对象与当前值的区别
> **对象回答“正在处理哪一份数据”，值回答“它当前保存了什么”。**同一个对象可以在允许的操作下改变值；这次赋值改变了已有对象的内容，没有创建另一个对象。

两个圆的横向位置也可以相同。在下面的独立示例中，两份位置数据的初值都是 `20.0`，随后只改变圆 A 的位置：

```cpp
double circle_x{20.0};
double other_circle_x{20.0};

circle_x = 35.0;
```

两条声明创建了两个对象。赋值之后，`circle_x` 保存 `35.0`，`other_circle_x` 仍然保存 `20.0`。相同的类型与数值不会把两个对象合并为同一个对象；本例分别保存两份位置数据，没有建立联动更新，改变其中一份不会自动改变另一份。

## 数据类型（Data Type）

绘图程序还需要记录图形数量。画面上只有两个圆时，数量是整数 `2`；圆的位置则可能落在刻度 20 与 21 之间，例如 `20.5`。这两项信息可以分别用 `int` 与 `double` 对象保存：

```cpp
int shape_count{2};
double circle_x{20.5};
```

`int` 是整数类型（integer type），用于表示一定范围内的整数，这里保存图形数量 `2`。`double` 是浮点类型（floating-point type），可以表示 `20.5` 这样的带小数的数值，也可以表示 `20.0`。

浮点数的范围（range）与精度（precision）都有限：范围涉及能够覆盖的数值大小，精度涉及某个数值附近能区分多细微的差别。因此，`double` 不能精确表示任意实数。

数据类型（data type，通常简称 type）规定对象能够表示哪些值，以及相关操作遵循什么规则。`int` 对象不能保存带小数部分的 `20.5`。如果把记录位置的对象定义为 `int`，下面的花括号初始化就会导致编译错误：

```cpp
int circle_x{20.5}; // 错误：此处不能用浮点数初始化整数
```

`int` 的花括号初始化不允许把浮点数转换为整数，因此这条声明不能通过编译。`circle_x` 这个名称不会改变类型规则；将对象的类型改为 `double`，就可以保存 `20.5`。

> [!IMPORTANT] 类型规定对象的表示与使用规则
> **类型规定对象能够表示的值，以及相关操作遵循的规则。**在同一个对象存在期间，合法操作可以改变它的当前值，但不会因此改变它的类型。

`int` 能表示负整数，而图形数量要求非负。这个业务条件需要由绘图程序保证，不能只依靠 `int` 类型。

`int` 与 `double` 都是 C++ 提供的内建类型。部分常用内建类型的用途如下：

| 表达的信息 | 常用类型 |
| --- | --- |
| [逻辑状态](05-boolean-type.md#两种逻辑状态) | `bool` |
| [整数](04-integer-types.md#有限存储中的整数) | `short`、`int`、`long`、`long long` 及其无符号形式 |
| [字符与编码单元](06-characters-and-text-encoding.md#从-bit-patterns-到字符) | `char`、`signed char`、`unsigned char` |
| [浮点数](07-floating-point-types.md#范围与精度) | `float`、`double`、`long double` |

这些用途不限定类型的业务含义：`double` 既可以记录位置，也可以记录半径。选择具体类型时，应根据相应小节的说明和目标 C++ 实现，核对它的取值范围与操作规则。

## 对象与存储

记录位置与数量的对象都具有类型，并占用存储（storage）。向位置对象赋值时，改变的是它当前保存的内容。

上述在 `main` 内创建的普通数值对象，生命周期（lifetime）从初始化完成时开始，在离开 `main` 函数体时结束。赋值发生在这段期间，改变当前值不会结束对象的生命周期。

> [!NOTE]
> **对象在 C++ 抽象机（abstract machine）中占用存储，不要求每个源代码对象都对应主内存里的某个固定位置。**具体实现可以在满足语言规则的前提下安排实际存储。

对象的存储大小以字节计量，每个字节由若干比特组成。

## 比特与字节（Bits and Bytes）

二进制（binary）表示用 `0` 和 `1` 组成不同的信息。每一位称为比特（bit），只能取这两个值；多位放在一起，就能区分更多组合。例如，两位可以组成 `00`、`01`、`10`、`11` 四种比特组合（bit pattern）。每增加一位，原有组合都能分别接上 `0` 或 `1`，组合数量就翻一倍。

C++ 用字节（byte）作为存储计量的基本单位。当前主流通用平台的一个字节包含连续的 8 个比特，因此有 $2^8=256$ 种不同的比特组合。

> [!IMPORTANT] 比特、字节与存储大小
> **比特表示一个 `0` 或 `1`；字节是 C++ 存储计量的基本单位，一个字节至少包含 8 个比特，具体位数由实现规定。**固定的 $N$ 个比特共有 $2^N$ 种组合；采用 8-bit byte 的实现中，一个字节有 256 种组合。

有限位数只能提供有限种组合，所以用固定大小的数值对象无法表示无限多个不同数值。但这些组合怎样对应数值，需要结合类型及其表示规则判断：组合总数不能直接当成某种类型的不同有效值的数量。

`int` 的有限取值范围限制了可记录的图形数量；`double` 的范围与精度限制了能够表示的位置数值。这些限制取决于存储大小和类型的表示规则。

> [!NOTE]
> 相同的比特组合按不同类型的规则解释，可能具有不同含义。**类型是对象在 C++ 语言模型中的属性，不要求在每个普通数值对象旁边自动保存一枚类型标签。**程序依据已经建立的类型关系使用数据；只观察一段原始字节，通常不能确定它应按 `int` 还是 `double` 的规则解释。
