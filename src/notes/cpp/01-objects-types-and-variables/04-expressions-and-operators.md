# 表达式与运算符（Expressions and Operators）

## 表达式（Expression）

变量让程序能够保存数据，但程序还需要读取和处理这些数据。C++ 中，描述一项计算并能够被求值（evaluation）的代码称为表达式（expression）。先看一个最简单的例子：

```cpp
8 + 4
```

这段代码要求程序计算 `8` 与 `4` 的和。对表达式进行计算的过程称为求值；求值完成后，这个表达式产生结果 `12`。

### 表达式的结果与数据类型

表达式经过求值不只产生一个结果，这个结果也具有确定的数据类型。在 `8 + 4` 中，`8` 和 `4` 都是 `int` 类型的整数字面量（integer literals）；表达式 `8 + 4` 的类型也是 `int`，求值结果是 `int` 值 `12`。

表达式的结果可以继续参与其他表达式，也可以用于初始化或赋值。无论这个结果之后被用于何处，当前表达式怎样求值、产生什么类型的结果，首先由表达式自身的组成和相应的语言规则决定。

## 运算符与操作数（Operators and Operands）

许多表达式由运算符和操作数组成。在表达式 `8 + 4` 中，`+` 称为运算符（operator），表示需要执行的运算；位于它两侧的 `8` 和 `4` 称为操作数（operands），表示参与运算的数据。`+` 需要两个操作数，因此它在这里属于二元运算符（binary operator）。

这里的 `binary` 指“拥有两个操作数”，与前文表示 `0` 和 `1` 的 binary（二进制）含义不同。

操作数不一定是直接写在代码中的数值。程序也可以读取变量当前保存的值，让它们参与表达式的求值：

```cpp
int front_tires{2};
int rear_tires{2};
int total_tires{front_tires + rear_tires};
```

执行第三行时，程序读取 `front_tires` 和 `rear_tires` 当前保存的值，对表达式 `front_tires + rear_tires` 求值并得到 `4`，再用这个结果初始化 `total_tires`。

## 算术运算符（Arithmetic Operators）

C++ 提供了一组算术运算符，用于让数值参与基本数学运算：

| 运算符 | 运算 | 示例 | 结果 |
|---|---|---|---|
| `+` | 加法 | `8 + 4` | `12` |
| `-` | 减法 | `8 - 4` | `4` |
| `*` | 乘法 | `8 * 4` | `32` |
| `/` | 除法 | `8 / 4` | `2` |
| `%` | 取余 | `8 % 3` | `2` |

前四种运算与通常的数学直觉基本一致；`%` 计算整数除法得到的余数。运算符 `/` 和 `%` 的具体结果还与操作数的数据类型有关，需要分别说明。
