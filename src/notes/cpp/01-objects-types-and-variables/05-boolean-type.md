# 布尔类型（Boolean Type）

## 两种逻辑状态

有些信息只需要回答一个问题：发动机是否正在运行、车门是否已经关闭、当前数据是否有效。这样的状态只有“是”和“否”两种可能，可以使用布尔类型（Boolean type）`bool` 表示：

```cpp
bool engine_running{false};

engine_running = true;
```

`true` 和 `false` 是 `bool` 仅有的两个值。赋值后，`engine_running` 仍然是原来的对象，只是当前值从 `false` 变成了 `true`。

**`bool` 用类型直接表达二元逻辑状态，而不是把普通整数约定为某种状态代码。**

## 与整数值的关系

在 C++ 的正式类型分类中，`bool` 属于整型（integral type），但它是一个独立类型。算术值转换为 `bool` 时，零转换为 `false`，非零值转换为 `true`；转换完成后的结果仍然只有两个可能值。

**“属于整型”描述的是类型系统中的分类关系，不表示 `bool` 应当作为只能保存 `0` 和 `1` 的普通计数器使用。**直接表达逻辑状态时，使用 `true` 和 `false` 比依赖数值转换更清楚。

## 值集合与存储大小

一个完整的 `bool` 对象至少占用一个 C++ byte；在当前主流实现中，它通常恰好占用 1 byte。

**对象占用多少 bits，与它在语言层面具有多少个有效值，是两个不同的问题。**不能因为一个 `bool` 对象通常占用 8 bits，就推断它能够保存 256 个不同的 `bool` 值。

## 二元模型的边界

`bool` 适合表示真正只有两种状态的信息。如果“未知”“尚未检查”或“发生故障”也是独立状态，单独一个 `bool` 就无法完整表达业务含义。此时应当选择能够明确列出全部状态的类型，而不是再约定某个隐藏值。
