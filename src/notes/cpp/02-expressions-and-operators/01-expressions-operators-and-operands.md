# 表达式、运算符与操作数（Expressions, Operators, and Operands）

## 表达式（Expression）

程序不仅需要保存数据，还需要描述怎样取得和处理这些数据。**在 C++ 中，能够按照语言规则被求值（evaluation）的一段代码称为表达式（expression）。**这里的求值不只表示算出一个数学答案，而是让程序确定这段代码所表示的结果或作用。

例如，下面三段代码都是表达式：

```cpp
8
front_tires
8 + 4
```

`8` 直接表示一个数值，`front_tires` 用名称指代一个已经存在的对象，`8 + 4` 则描述一次加法运算。**表达式可以很小，也可以由更小的表达式逐层组合而成。**

## 运算符与操作数（Operators and Operands）

**运算符（operator）规定需要执行什么运算，操作数（operand）则是参与这次运算的表达式。**例如：

```cpp
8 + 4
```

其中，`+` 是运算符，`8` 和 `4` 是它的两个操作数。由于这里的 `+` 作用于两个操作数，因此它在这次使用中是二元运算符（binary operator）。

这里的 `binary` 指“拥有两个操作数”，与前文表示 `0` 和 `1` 的 binary（二进制）含义不同。

本章涉及的基本运算符可以分为五类：

| 类别 | 运算符 | 基本作用 |
|---|---|---|
| 算术运算符 | `+`、`-`、`*`、`/`、`%` | 对数值进行算术运算 |
| 赋值运算符 | `=`、`+=`、`-=`、`*=`、`/=`、`%=` | 修改已有对象保存的值 |
| 自增与自减运算符 | `++`、`--` | 按照对象类型的规则将其值增加或减少 `1` |
| 比较运算符 | `==`、`!=`、`<`、`<=`、`>`、`>=` | 比较两个值，并产生布尔结果 |
| 逻辑运算符 | `!`、`&&`、`\|\|` | 反转或组合布尔条件 |

同一个符号在不同表达式中可能具有不同用法。例如，`-` 既可以作为二元运算符执行减法，也可以作为一元运算符（unary operator）表示负号。**运算符的含义不能只看符号本身，还需要结合它拥有的操作数及相应的语言规则判断。**
