# 语句与复合语句（Statements and Compound Statements）

## 语句与顺序执行

以下代码片段各自独立，均放在 `main` 函数体内。

用一个整数记录图形数量，先把数量设为 `3`，再增加 `1`：

```cpp
int shape_count{3};
shape_count += 1;
```

这两行各是一条语句（statement），是 C++ 描述程序执行过程的基本语法单位：

- `int shape_count{3};` 是声明语句（declaration statement），在这里定义一个对象，并用 `3` 初始化。
- `shape_count += 1;` 是表达式语句（expression statement）。其中的 `shape_count += 1` 是表达式，末尾的分号使它构成完整语句；执行时把已有对象的值增加 `1`。

两条语句依次执行，所以先创建保存 `3` 的对象，再将它改为保存 `4`。

> [!IMPORTANT] 声明语句与表达式语句
> **这里的变量声明在代码块中构成声明语句；表达式在语句位置后接分号，构成表达式语句。**它们都是语句，但具有不同的语法结构：声明可以定义对象，表达式语句则对表达式求值。不能只因为两者都以分号结束，就把声明当成表达式。

## 复合语句与代码块（Compound Statements and Blocks）

给同样的两条语句加上一对花括号：

```cpp
{
    int shape_count{3};
    shape_count += 1;
}
```

花括号内仍然是一条声明语句和一条表达式语句，数量仍从 `3` 变为 `4`。新增的花括号把它们组织成一个整体，整个结构本身也是一条语句。

> [!IMPORTANT] 复合语句怎样组合语句
> **由一对花括号包围、把零条或多条语句组成一条语句的结构，称为复合语句（compound statement），也称为代码块（block）。**整个代码块占据一条语句的位置，内部语句仍保留各自的结构；在这里的顺序执行代码中，先执行前面的语句，再执行后面的语句。

此前使用的 `main` 函数体也是一个代码块。在它的内部再写一个代码块，就形成了嵌套。

## 嵌套代码块

一个代码块可以包含另一个代码块。下面仍然只创建一个图形计数对象，内层代码块修改它两次，然后外层再修改一次：

```cpp
{
    int shape_count{3};

    {
        shape_count += 1;
        shape_count += 1;
    }

    shape_count += 1;
}
```

外层代码块包含三条语句：一条声明语句、一个内层复合语句，以及最后一条表达式语句。内层复合语句又包含两条表达式语句。

按当前代码的执行顺序，计数依次变化：

| 执行位置 | 执行的内容 | 执行后的计数 |
| --- | --- | ---: |
| 外层开头 | 定义并初始化 `shape_count` | 3 |
| 内层第一条语句 | 增加 `1` | 4 |
| 内层第二条语句 | 再增加 `1` | 5 |
| 内层执行完毕，继续外层 | 执行最后一次增加 `1` | 6 |

内层没有声明新的 `shape_count`，其中的修改作用于外层创建的同一个对象。内层代码块执行完毕后，程序继续执行外层位于它后面的语句，最终计数为 `6`。

缩进呈现了嵌套关系，但真正建立代码块边界的是花括号。只改变换行或缩进，不会把语句放入另一个代码块。

## 复合语句与分号

代码块把语句组织起来，不会替代内部语句各自需要的结束标记。

> [!IMPORTANT] 复合语句的结束边界
> **复合语句由右花括号 `}` 结束，本身不需要追加分号。**其中的声明语句和表达式语句仍然以分号结束；换行和缩进不能代替这些语法标记。

没有包含任何语句的 `{}` 是合法的空复合语句。单独一个分号也是合法语句，称为空语句（null statement），不执行操作。下面的写法都放在函数体内，但结构不同：

| 写法 | 包含的语句 |
| --- | --- |
| `{}` | 一条空复合语句 |
| `;` | 一条空语句 |
| `{};` | 一条空复合语句，后面再跟一条空语句 |

因此，在这里的函数体语境中，代码块后写分号仍然合法，但这个分号不属于前面的复合语句。书写这样的独立代码块时，直接以 `}` 结束即可，避免添加没有用途的空语句。

## 花括号的含义取决于语法位置

同一段代码中可以同时出现两种用途的花括号。回看前面的计数示例：

| 花括号所在位置 | 作用 |
| --- | --- |
| `int shape_count{3};` 中变量名后的 `{3}` | 初始化器，为对象提供初值 `3` |
| 包围声明、赋值等语句的一对花括号 | 形成复合语句，把内部语句组织成一个整体 |

> [!IMPORTANT] 初始化器与代码块
> **花括号的含义要结合语法位置判断。**这里，变量声明中用于初始化的花括号建立对象的初始状态；语句位置中包围语句序列的花括号构成复合语句。两者不会因为都使用 `{}` 而成为同一种结构。
