# 函数定义与调用（Function Definitions and Calls）

此前的代码已经能够创建对象、计算结果，并通过条件与循环改变执行过程。现在要把一项工作起一个名字，让程序在需要时调用它。C++ 使用函数（function）组织这样的工作。

## 把一段行为命名为函数

先用一个始终返回默认数量 `4` 的函数，观察定义和调用的关系。下面是完整程序；`default_count` 定义在 `main` 外面，调用则写在 `main` 里面：

```cpp
#include <iostream>

int default_count() {
    return 4;
}

int main() {
    int count{default_count()};
    std::cout << count << '\n'; // 4
    return 0;
}
```

`int default_count() { ... }` 是一条函数定义（function definition）。它说明这项工作叫什么、接收什么输入、返回什么结果，以及调用时执行哪些语句。逐项对应到当前代码：

| 组成部分 | 当前示例 | 含义 |
| --- | --- | --- |
| 返回类型 | `int` | 函数调用产生的结果类型 |
| 函数名 | `default_count` | 标识这项可调用行为的名称 |
| 参数列表 | `()` | 表示当前函数不接收输入数据 |
| 函数体 | `{ return 4; }` | 调用时执行的语句；这里把 `4` 作为结果返回 |

函数体沿用已经建立的代码块模型，可以包含声明、表达式语句、选择语句和循环语句。定义末尾的右花括号已经结束整条函数定义，后面不再添加分号。

**函数定义建立的是一项可以被调用的行为；执行到函数调用时，程序才进入函数体。**

## 调用才会进入函数体

程序中的 `default_count()` 是一次函数调用（function call）。函数名标识要调用的行为，名称后的圆括号表示发起调用。执行 `int count{default_count()};` 时：

1. 程序先去执行 `default_count` 的函数体；
2. `return 4;` 这条返回语句（return statement）把 `4` 作为本次调用的 `int` 结果，随后结束这次调用；
3. 程序回到 `main` 中的调用位置，用得到的 `4` 初始化 `count`；
4. 后面的输出语句读取 `count`，所以显示 `4`。

即使函数不接收输入，调用语法中的空圆括号也不能省略。它们表示这里正在发起一次调用，而不是只写出函数名称。

**定义描述调用时做什么，调用才真正使执行路径进入函数体。**当前调用通过 `return` 正常完成后，外围表达式继续使用它产生的结果。

## 函数调用也是表达式

当前调用得到的 `4` 还可以继续参与计算。在原程序的 `return 0;` 前面加上下面两行：

```cpp
int next_count{default_count() + 1};
std::cout << next_count << '\n'; // 5
```

这次调用仍返回 `4`，加法得到 `5`，再用它初始化 `next_count`。原程序先输出 `4`，增加的输出语句随后显示 `5`。

**本例中，`default_count` 声明返回 `int`，调用表达式 `default_count()` 的类型也是 `int`。**因此，它可以像已经见过的整数表达式一样参与加法；调用提供的结果成为外围表达式的操作数。

同一个函数可以出现在多个调用表达式中。每次执行到调用时，函数体都会为这一次调用重新执行；函数定义本身不会被复制，也不会因曾经调用过一次而保存某条执行路径。

## 让函数边界表达意图

函数的价值不只在于减少重复代码。名称能够说明一组语句共同完成什么，返回类型则形成调用者与函数体之间的边界。

`default_count` 说明调用是为了取得一个默认数量。名称把结果的用途带到调用位置，读者无需每次展开函数体，就能识别当前操作的意图。

**一个函数应当围绕一项能够被清楚命名的工作组织语句。**如果名称必须同时罗列许多彼此独立的动作，通常说明函数边界没有准确对应问题本身。
