# main 与程序入口（The Main Function and Program Entry）

普通函数调用总是由某个正在执行的位置发起，而整个程序必须有一个进入主体的起点。**在通常运行于操作系统之上的托管环境（hosted environment）中，C++ 将名为 `main` 的特殊函数指定为程序入口。**

## main 函数的基本形式

不接收命令行参数的基本形式是：

```cpp
int main() {
    return 0;
}
```

`main` 仍然具有此前认识的函数结构：

| 代码 | 作用 |
|---|---|
| `int` | 返回类型 |
| `main` | 函数名 |
| `()` | 空参数列表 |
| `{ return 0; }` | 函数体 |

它的特殊之处在于所承担的角色与相应语言规则。**托管程序需要提供一个位于全局作用域（global scope）的 `main` 定义，C++ 实现负责调用它，并由此把控制交给程序的主体。当前可以将全局作用域理解为源代码最外层的作用域：`main` 不嵌套在另一个函数或代码块中。**

**`main` 的返回类型必须是 `int`；`void main()` 不是标准 C++ 程序所允许的入口形式。**

## 程序的终止状态

**从 `main` 返回的 `int` 值会作为程序的终止状态交给运行环境。标准保证返回 `0` 表示程序成功终止：**

```cpp
int main() {
    return 0;
}
```

其他数值的具体含义可能受实现与运行环境约定影响，不能仅凭 C++ 语言规则为任意非零数值赋予统一含义。

**`main` 还拥有一项特殊规则：如果控制流自然执行到函数体末尾，效果等价于执行 `return 0;`。因此，下面的程序也表示成功终止：**

```cpp
int main() {
}
```

**这项规则只应当用于 `main`。普通非 `void` 函数不能因此省略所有执行路径所需的返回结果。**

## 一个包含普通函数的程序

`main` 可以调用程序中的普通函数：

```cpp
int add(int left, int right) {
    return left + right;
}

int main() {
    int total{add(2, 3)};
    total += 1;

    return 0;
}
```

程序进入 `main` 后创建局部对象 `total`。初始化器调用 `add(2, 3)`，普通函数完成后返回 `int` 值 `5`，`main` 随后继续执行。执行 `return 0;` 时，**`main` 中仍然存活、具有自动存储期的局部对象先按照相应规则结束生命周期，程序再以成功状态正常终止。**

这里将 `add` 的定义写在 `main` 之前，是因为调用位置需要预先知道这个函数的存在及其类型信息。

## `main` 不是普通的调用目标

虽然 `main` 具有函数的外形，**但程序自身不能像调用 `add` 一样显式调用 `main`，也不能取得它的地址。一个程序只能定义一个 `main`，它允许采用的参数形式由 C++ 标准规定。**

**将 `main` 称为程序入口，也不表示它一定对应可执行文件运行的第一条机器指令。C++ 实现和运行环境可能需要先完成启动工作，之后才进入 `main` 的函数体。`main` 表示 C++ 程序主体开始执行的位置，而不是对底层启动过程的完整描述。**

## 带命令行参数的形式

托管程序还可以让 `main` 接收启动程序时提供的命令行参数，常见形式是：

```cpp
int main(int argc, char* argv[]) {
    return 0;
}
```

`argc` 与 `argv` 是约定俗成的参数名称，并不是固定关键字。

**`argc` 来自参数数量（argument count），表示本次启动向程序提供了多少项命令行参数。`argv` 来自参数向量（argument vector），提供这些参数对应的文本。**

当 `argc > 0` 时，`argv[0]` 表示用于启动程序的名称，也可能为空；`argv[1]` 到 `argv[argc - 1]` 表示其余命令行参数。例如，以 `vehicle --mode test` 启动程序时，常见环境会令 `argc == 3`，三项文本依次对应 `vehicle`、`--mode` 和 `test`。

`char* argv[]` 的类型结构涉及数组、指针和 C 风格字符串，将在这些概念建立后单独说明。

## 托管环境与独立环境

**普通桌面、服务器和命令行程序通常运行于托管环境。C++ 也允许独立环境（freestanding environment），例如某些不依赖完整操作系统运行的嵌入式程序；这类实现是否要求提供 `main`，由具体实现规定。**

托管程序可以使用标准形式 `int main()` 作为程序入口。
