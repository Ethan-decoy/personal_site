# 字面量及其类型（Literals and Their Types）

## 直接写在源代码中的值

初始化对象或组成表达式时，经常需要直接写出一个值：

```cpp
int wheel_count{4};
double pressure{2.4};
char grade{'A'};
bool engine_running{false};
```

其中的 `4`、`2.4`、`'A'` 和 `false` 都是字面量（literal）。**字面量是由源代码中的特定字符序列直接表示一个值的语法形式；它不需要先声明名称，再通过名称读取已有对象。**

**字面量本身也是表达式，而且每个字面量都有自己的类型。`4` 是 `int`，`2.4` 是 `double`，`'A'` 是 `char`，`false` 是 `bool`。初始化目标的类型不会反过来决定字面量原本的类型：**

```cpp
long long wheel_count{4};
```

这里的 `4` 仍然是 `int` 字面量；它产生的值随后用于初始化 `long long` 对象。区分“字面量自身的类型”与“接收结果的对象类型”，是理解后续类型转换的基础。

## 整数字面量

同一个整数值可以使用不同进制写出：

| 写法 | 进制 | 十进制值 |
|---|---:|---:|
| `42` | 十进制 | 42 |
| `052` | 八进制 | 42 |
| `0x2A` | 十六进制 | 42 |
| `0b101010` | 二进制 | 42 |

二进制前缀可以写成 `0b` 或 `0B`，十六进制前缀可以写成 `0x` 或 `0X`，十六进制中的 `A～F` 也不区分大小写。八进制没有由两个字符组成的专门前缀，**而是由开头的 `0` 标识，因此 `010` 表示十进制的 8，而不是十进制的 10。**普通计数通常直接使用十进制；其他进制应当用于表达数据本身的组织方式。

较长的数字序列可以在数字之间加入单引号作为数字分隔符（digit separator）：

```cpp
int population{1'250'000};
int byte_mask{0b1111'0000};
int color_value{0xFF'80'20};
```

**分隔符不参与数值计算，`1'250'000` 与 `1250000` 表示相同的值。它也不规定必须每三位分组；二进制数据常按 4 bits 或 8 bits 分组，**只要分组方式能帮助读者看出结构即可。

### 整数后缀与候选类型

**当前已介绍的标准整数类型涉及的常用后缀如下，它们用来约束字面量自身的类型：**

```cpp
42u    // unsigned int
42L    // long int
42LL   // long long int
42UL   // unsigned long int
42ULL  // unsigned long long int
```

`u`、`l`、`ll` 可以使用对应的大写形式，但两个 `long long` 字母必须同为 `ll` 或同为 `LL`。代码通常使用大写 `L`，避免小写 `l` 与数字 `1` 混淆。无符号后缀可以位于长度后缀之前或之后，例如 `42ULL` 与 `42LLU` 都合法。

**没有显式后缀时，字面量也不是“没有类型”。C++ 会根据进制、后缀和数值，从对应候选列表中选择第一个能够表示该值的类型：**

| 后缀 | 十进制候选类型 | 二、八、十六进制候选类型 |
|---|---|---|
| 无 | `int` → `long int` → `long long int` | `int` → `unsigned int` → `long int` → `unsigned long int` → `long long int` → `unsigned long long int` |
| `u` | `unsigned int` → `unsigned long int` → `unsigned long long int` | 同左 |
| `L` | `long int` → `long long int` | `long int` → `unsigned long int` → `long long int` → `unsigned long long int` |
| `UL` | `unsigned long int` → `unsigned long long int` | 同左 |
| `LL` | `long long int` | `long long int` → `unsigned long long int` |
| `ULL` | `unsigned long long int` | 同左 |

只要 `42` 能由 `int` 表示，它的类型就是 `int`；编译器不会因为它后来用于初始化 `long long` 对象，就跳过列表中的 `int`。十进制无后缀列表只包含有符号类型，其他进制的列表则会较早考虑无符号类型，**因此仅仅改写进制，也可能改变较大字面量的类型。**

如果表中的标准整数类型都无法表示数值，实现还可能采用语言允许的扩展整数类型；若所有允许的类型都无法表示，该字面量会使程序不合法。**后缀因此不是“越大越安全”的装饰，而是程序对字面量类型作出的明确选择。**

### 负号不属于字面量

**整数语法本身没有负数字面量：**

```cpp
-42
```

其中 `42` 是整数字面量，前面的 `-` 是一元负号运算符。**程序先按照整数字面量规则确定 `42` 的类型，再对它应用负号。`-42LL` 同样是对 `long long` 字面量 `42LL` 应用一元负号，而不是一个整体的“负 `long long` 字面量”。**

这一区别在表示范围边缘尤其重要：编译器必须先确认不带负号的部分能由某个候选类型表示，不能先把整个文本当成负值再选类型。`-1u` 中的 `1u` 也已经是无符号字面量，一元负号不会把它改成有符号字面量。

## 浮点字面量

浮点字面量可以使用小数点或指数部分：

```cpp
2.4       // 2.4
2.        // 2.0
.5        // 0.5
2e3       // 2 × 10³，即 2000.0
1.25e-2   // 1.25 × 10⁻²，即 0.0125
```

十进制指数由 `e` 或 `E` 引入，指数自身可以带 `+` 或 `-`。`2e3` 虽然没有小数点，仍然是浮点字面量；单独的 `2` 则是整数字面量。数字分隔符也能出现在浮点数字序列中，例如 `1.602'176e-19`。

C++ 还支持十六进制浮点字面量。它以 `0x` 开头，并使用 `p` 或 `P` 引入以 2 为底的指数：

```cpp
0x1.8p1 // (1 + 0.5) × 2¹，即 3.0
```

十六进制有效数字按 16 进制解释，指数中的数字仍按十进制书写；`p` 指数是这种写法不可缺少的部分。对于目前已介绍的三种标准浮点类型，字面量类型由后缀决定：

| 后缀 | 类型 | 示例 |
|---|---|---|
| 无 | `double` | `2.4` |
| `f` 或 `F` | `float` | `2.4F` |
| `l` 或 `L` | `long double` | `2.4L` |

**`2.4` 的类型是 `double`，`2.4F` 的类型是 `float`。**

**若数学值仍在字面量类型的可表示范围内、但不能被精确表示，字面量会取得相邻的可表示值之一；若数学值超出该类型的可表示范围，程序不合法。**后缀改变浮点类型，也可能改变表示精度。负浮点数与负整数相同，`-2.4` 是对 `2.4` 应用一元负号。

## 字符字面量与转义序列

普通字符字面量使用单引号，类型是 `char`：

```cpp
'A'
'7'
' '
```

**`'7'` 表示数字字符 `7`，不是整数值 7。**无法直接写出或不易辨认的字符可以使用以反斜杠开头的转义序列：

| 转义 | 含义 | 转义 | 含义 |
|---|---|---|---|
| `\n` | 换行 | `\t` | 水平制表 |
| `\r` | 回车 | `\\` | 反斜杠 |
| `\'` | 单引号 | `\"` | 双引号 |
| `\0` | 数值为零的字符 | `\a`、`\b`、`\f`、`\v` | 警报、退格、换页、垂直制表 |

**`'\n'` 表示换行对应的单个编码值，不是反斜杠与字母 `n` 两个字符。**数值转义还可以写成 `'\101'`、`'\x41'`；C++23 新增的带边界形式为 `'\o{101}'` 和 `'\x{41}'`。在 ASCII 兼容编码中，这四个示例都表示编码值 65，并且该值可以由普通 `char` 表示。

**不要用 `'AB'` 表示文本；这种多字符字面量只有条件地受到支持，其值具有实现相关性。**

## 布尔字面量

**`true` 和 `false` 是仅有的两个布尔字面量，类型都是 `bool`，并且不加引号。`0` 和 `1` 是 `int` 字面量；它们虽然可以按转换规则得到 `false` 和 `true`，自身却不是布尔字面量。**

## 使用原则

**普通整数默认使用十进制，普通浮点数默认使用没有后缀的 `double` 字面量。二进制、八进制、十六进制、数字分隔符和类型后缀，**应当在它们能够表达数据的真实结构或所需类型时使用。

**不要为了压下编译器警告而随意改进制或添加后缀。警告通常提示表达式类型与接收类型之间存在需要确认的关系，应当先判断类型选择和转换是否符合数据含义。**

尤其要留意十进制整数前的 `0`：它会把字面量改成八进制，既可能改变数值，也可能掩盖输入错误。单引号中的字符字面量可以表示一个 `char` 值；双引号包围的内容不是单个 `char`，不能按字符字面量规则判断其类型和内容。

相关规则可参阅 C++23 工作草案 N4950 中的[整数字面量](https://timsong-cpp.github.io/cppwp/n4950/lex.icon)、[浮点字面量](https://timsong-cpp.github.io/cppwp/n4950/lex.fcon)与[字符字面量](https://timsong-cpp.github.io/cppwp/n4950/lex.ccon)。
