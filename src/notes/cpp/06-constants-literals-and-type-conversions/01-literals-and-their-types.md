# 字面量及其类型（Literals and Their Types）

## 写在源代码中的值

对象能够在程序运行期间保存值，而有些值需要直接写进源代码：

```cpp
int wheel_count{4};
double front_left_pressure_kpa{240.5};
char transmission_mode{'D'};
bool engine_running{true};
```

其中的 `4`、`240.5`、`'D'` 和 `true` 都是**字面量（literal）**。字面量是源代码中直接表示一个值的记号；它参与表达式求值，但并不是从某个已有的具名对象中读取值。

## 字面量本身也有类型

字面量不只是纸面上的数字或字符。编译器会先按照字面量的写法确定它的值和类型，随后再根据使用它的语境决定是否需要类型转换。

```cpp
int wheel_count{4};
double pressure_kpa{4};
```

两处 `4` 都是 `int` 类型的整数字面量。第二行最终创建的是 `double` 对象，但目标对象的类型不会倒过来改变字面量本身的类型；初始化过程会在需要时把 `int` 值转换为 `double` 值。

> [!IMPORTANT]
> 字面量的类型先由自身写法确定，使用它的语境再决定是否需要转换。

## 整数字面量的进制

整数字面量（integer literal）可以使用二进制、八进制、十进制或十六进制书写：

| 进制 | 写法 | 表示的十进制值 |
| --- | --- | ---: |
| 二进制 | `0b1100` | 12 |
| 八进制 | `014` | 12 |
| 十进制 | `12` | 12 |
| 十六进制 | `0xC` | 12 |

前缀决定数字序列采用的进制。尤其需要注意：以 `0` 开头的非零整数字面量按照八进制解释，因此 `012` 表示十进制的 10，而不是 12。除非确实需要八进制，整数前面不应添加装饰性的零。

单引号可以作为数字分隔符，提高较长数字的可读性：

```cpp
int maximum_rotation_per_minute{12'000};
long color_mask{0xFF'00'7A};
```

分隔符不会改变字面量的值或类型。

## 整数字面量的类型选择

没有后缀的十进制整数字面量会依次尝试 `int`、`long int` 和 `long long int`，选择其中第一个能够表示该值的类型。

无后缀的二进制、八进制和十六进制形式，则在每个有符号候选后紧接对应的无符号候选：先 `int` 与 `unsigned int`，再 `long int` 与 `unsigned long int`，最后 `long long int` 与 `unsigned long long int`。它们同样选择顺序中第一个能够表示该值的类型。

因此，值由数字及其进制解释，而类型由**进制类别、后缀和可表示范围**共同决定。对于值较大的无后缀字面量，改变进制写法也可能改变最终类型。

例如，明确假定 `int` 为 32 位、`long` 为 64 位，两种写法都表示 $2^{31}$，但候选顺序不同：

| 写法 | 前几个候选及范围检查 | 最先成功的类型 |
| --- | --- | --- |
| `2147483648` | `int` 不能表示，接着尝试的 `long` 能表示 | `long` |
| `0x80000000` | `int` 不能表示，接着尝试的 `unsigned int` 能表示 | `unsigned int` |

这里没有先得到一个 `int` 再转换；编译器直接按各自的候选列表确定字面量类型。数学值相同，参与后续运算的类型仍可能不同。上述结果依赖给定的类型范围，不能照搬到所有实现。

需要直接掌握的是“由写法确定候选，再按值域选第一项”的关系。数值超出常用范围，或需要核对某种后缀时，先确认目标实现的类型范围，再查文末整数字面量条款的候选表；不必把所有后缀组合展开成记忆清单。

常用后缀可以限制编译器选择类型时使用的候选集合：

| 示例 | 当前字面量的类型 |
| --- | --- |
| `42` | `int` |
| `42U` | `unsigned int` |
| `42L` | `long int` |
| `42LL` | `long long int` |
| `42ULL` | `unsigned long long int` |

后缀不是对一个已经存在的值再做类型转换，而是**整数字面量写法本身的一部分**。工程代码通常使用大写 `L`，避免小写 `l` 与数字 `1` 混淆。

如果一个整数字面量的值无法由语言为该写法允许的任何整数类型表示，程序不合法，编译器必须诊断。

## 负号不属于整数字面量

`-42` 看起来像一个负整数字面量，但词法上只有 `42` 是整数字面量；前面的 `-` 是一元负号运算符：

```cpp
int outside_temperature_c{-42};
```

花括号中的内容是表达式 `-42`：先确定正整数字面量 `42` 的类型，再对它应用一元负号。正负号不会参与整数字面量候选类型的选择。

## 浮点、字符与布尔字面量

浮点字面量（floating-point literal）的常用后缀直接决定其类型：

| 示例 | 类型 |
| --- | --- |
| `2.4` | `double` |
| `2.4F` | `float` |
| `2.4L` | `long double` |

`2.4e2` 使用科学计数法表示 240.0；没有后缀，因此类型仍是 `double`。十进制小数不一定能够由对应的浮点类型精确表示，具体原因可以回看[浮点类型](../01-objects-types-and-variables/07-floating-point-types.md#可表示值与舍入)及其附章。

单引号包围的 `'A'` 是字符字面量，在当前使用的普通形式下类型是 `char`；`true` 与 `false` 是布尔字面量，类型是 `bool`。

不同字面量的外形既表达值，也携带类型信息。**选择字面量写法时，应让进制、后缀和分隔方式服务于数据的真实含义，而不是只追求代码外观。**
