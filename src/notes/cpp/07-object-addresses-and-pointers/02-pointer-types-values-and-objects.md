# 指针类型、指针值与指针对象（Pointer Types, Pointer Values, and Pointer Objects）

## 取得对象的地址

对象有自己的存储位置。把指向它的值保存下来，程序就能记录当前选定的访问目标。

这里从已经初始化、可以修改的普通基本类型对象出发，讨论内建取地址操作。以下代码片段均放在 `main` 函数体内；注明接续时沿用前面的定义，其余片段各自独立。

`int*` 读作“指向 `int` 的指针”，是一种指针类型（pointer type）。内建的一元取地址运算符（address-of operator）`&` 作用于这里的对象名称时，会产生指向该对象的指针值：

```cpp
int value{7};
int* target{&value};
```

第一行定义一个保存整数 `7` 的 `int` 对象。第二行定义 `target`，其类型是 `int*`；初始化器 `{&value}` 用取地址表达式 `&value` 的结果，为这个指针对象建立初值。

在声明语法中，`*target` 构成指针声明符（pointer declarator），说明 `target` 具有指向 `int` 的指针类型。书写时把 `*` 靠近类型，写成 `int* target`，并保持一条声明只定义一个对象。

这条定义中的三个层次分别是：

| 层次 | 本例中的对应内容 | 含义 |
| --- | --- | --- |
| 指针类型 | `int*` | 指向 `int` 的指针类型 |
| 指针值 | `&value` 求值得到的值 | 表示指向 `value` 的关系 |
| 指针对象 | `target` | 一个 `int*` 对象，保存上面的指针值 |

`value` 是被指向的目标对象，保存的是整数 `7`；`target` 保存的是指向 `value` 的指针值。取地址操作取得指向这个对象的值，不读取并复制它当前保存的整数。

> [!IMPORTANT] 指针类型、指针值与指针对象
> **指针类型包含所指类型的信息；指针值用于表达指向关系；指针对象是保存指针值的独立对象。**取地址表达式产生指针值，指针变量的定义建立指针对象，初始化则为它设置初值。

上例的 `&value` 通过对象名称指定已经存在的对象。整数字面量 `42` 在这里提供一个数值，不能直接被取地址：

```cpp
int* target{&42}; // 错误：不能直接对整数字面量取地址
```

## 指针类型约束目标类型

取一个 `int` 对象的地址会产生 `int*` 值；把目标对象的类型改为 `double`，取地址结果的类型也相应变为 `double*`。下面是独立的错误示例，目标对象的数值仍为 `7`，但类型已经改变：

```cpp
double value{7.0};
int* target{&value}; // 错误：double* 不能初始化 int*
```

这里的错误发生在初始化的类型检查中。`&value` 具有 `double*` 类型，不能直接初始化 `int*` 对象；保存指向这个 `double` 对象的值，应使用相应的 `double*` 类型。

> [!IMPORTANT] 指针类型与所指类型
> **内建取地址操作的结果类型保留所指对象的类型信息；`int` 对象对应 `int*`，`double` 对象对应 `double*`。**指针对象的初始化必须满足相应的类型转换规则，不能因为都表示地址就任意混用。所指类型也约束了之后能够通过该指针进行的访问。

指针类型由所指类型构成，`int*` 是由 `int` 构成的复合类型（compound type）之一。指针类型不属于整数类型；指针值的具体位模式（bit pattern）由实现决定，不能把它当作某个固定整数格式。

## 指针对象与目标对象彼此独立

首例中的 `value` 与 `target` 各自占据存储。`target` 自身的地址用于定位这个指针对象，它保存的指针值则表示目标 `value` 的地址；指针对象自己的地址与它保存的值，需要分别判断。

接续首例，执行下面的赋值：

```cpp
value = 9;
```

赋值后，`value` 保存整数 `9`；`target` 中的指针值没有改变，仍然指向同一个 `value` 对象。目标对象的当前数值与指针对象保存的指向关系是两个不同的判断。

> [!IMPORTANT] 指针对象与目标对象的独立性
> **指针对象有自己的存储、地址和生命周期，与目标对象彼此独立。**取得并保存对象地址，不会复制目标对象，也不会延长目标的生命周期。指针对象本身仍然存在，也不能据此认定目标仍在生命周期内。
