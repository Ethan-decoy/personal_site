# 间接访问与被指对象（Indirection and Pointees）

## 沿指针回到原对象

指针对象保存指向某个对象的值。间接访问让程序沿着这条指向关系，读取或修改目标对象。

下面讨论内建的间接访问，目标是已经初始化、可以修改的普通 `int` 对象。所有代码片段均位于同一个 `main` 函数体内，并按顺序接续：

```cpp
int value{7};
int* target{&value};
```

`target` 保存指向 `value` 的指针值。一元 `*` 是间接运算符（indirection operator）；对指针执行这种操作通常称为解引用（dereferencing）。表达式 `*target` 读取 `target` 当前保存的指针值，并据此指定原来的 `value` 对象。这个被指向的对象称为被指对象（pointee）。

> [!IMPORTANT] 间接访问与被指对象
> **指针确实指向可访问的对象时，内建一元 `*` 指定的是这个被指对象，本身不创建它的副本。**`target` 指定指针对象，`*target` 则指定其指针值所指向的对象；后续是读取还是修改目标，取决于表达式所在的语境。

把 `*target` 用在需要整数值的初始化器中，就能读取被指对象当前保存的值：

```cpp
const int saved{*target};
```

这条定义先通过 `target` 中的指针值确定 `value`，再读取其中保存的整数 `7`，用这个值初始化独立的 `saved` 对象。`saved` 保存的是读取时取得的整数；它没有保存指向 `value` 的指针。

## 通过指针修改被指对象

`value` 是可以修改的 `int` 对象，通过 `*target` 也能把它指定为赋值目标。接续上例：

```cpp
*target = 9;
```

赋值的左操作数 `*target` 指定 `value`，因此这条语句把 `value` 保存的整数改为 `9`。在当前例子中，它与 `value = 9;` 修改的是同一个对象。

比较这次赋值前后的状态：

| 对象 | 赋值前 | 赋值后 |
| --- | --- | --- |
| `value` | 保存整数 `7` | 保存整数 `9` |
| `saved` | 保存整数 `7` | 仍保存整数 `7` |
| `target` | 保存指向 `value` 的指针值 | 仍保存同一个指针值，指向 `value` |

> [!IMPORTANT] 复制数值与修改原对象
> **用被指对象的当前值初始化另一个普通 `int` 对象，会保存一份独立数值；通过间接访问赋值，则修改被指对象。**数值副本不会随原对象的后续变化自动更新。对这里的被指 `int` 赋值，也不会改变指针对象保存的指向关系。

## 同一个符号，不同的语法角色

`*` 的含义取决于它出现的语法位置：

| 写法 | `*` 的角色 | 结果 |
| --- | --- | --- |
| `int* target{&value};` | 指针声明符的一部分 | 定义并初始化指针对象 `target` |
| `*target` | 一元间接运算符 | 指定指针当前指向的 `int` 对象 |

表中第一条语句是对象的定义，也是声明。它声明 `target` 的名称与类型，定义这个指针对象，并用 `&value` 的结果完成初始化；其中的 `*` 说明指针类型，不执行间接访问。

第二种写法是表达式，`*` 参与求值。判断这个符号的作用，应看它处在声明符中，还是作为表达式的运算符使用。声明不一定定义对象，不能把声明位置的 `*` 理解为一次访问目标的操作。

## 间接访问需要有效目标

在上面的代码中，`target` 已经用 `&value` 初始化，`value` 也已经取得确定值，并在这些语句执行期间保持存活。它的类型是 `int`，通过这里的 `int*` 可以读取和修改它。这些已知条件共同保证了示例中的访问成立。

> [!IMPORTANT] 间接访问的有效性前提
> **通过指针读取或修改普通对象前，应先保证指针具有可使用的确定值，并确实指向仍在生命周期内、允许按相应类型访问的对象。**读取普通 `int` 的值时，目标应已通过初始化或赋值取得确定值；修改时，这条访问路径还必须允许修改。指针对象本身仍然存在，不能证明这些条件成立。

> [!WARNING]
> `*` 不会替程序检查目标是否可访问，也不会在目标不可访问时提供可供判断的“空结果”。如果所指存储的存储期已经结束，指针仍保存原来的值，对它执行间接访问本身就会产生未定义行为，并不以随后读取或写入对象为前提。不能把解引用当作确认目标有效的办法。
