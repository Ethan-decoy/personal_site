# 指针复制、重新指向与别名关系（Pointer Copying, Reseating, and Aliasing）

## 复制的是指针值

同一个对象可以有多条访问路径。把一个指针对象当前保存的值复制给另一个指针对象，就能让它们指向同一个目标。

以下是一个独立示例，各代码片段按顺序放在同一个 `main` 函数体内。指针都已初始化，所指的普通 `int` 对象在访问期间保持存活，并且允许通过对应指针修改：

```cpp
int value{7};
int* target{&value};
int* alias{target};
```

第二行用 `&value` 的结果初始化 `target`。第三行定义另一个 `int*` 对象 `alias`，初始化器 `target` 读取的是 `target` 当前保存的指针值。因此，`alias` 也指向 `value`；初始化它时没有复制目标对象，也没有读取 `value` 保存的整数作为初值。

> [!IMPORTANT] 指针值的复制与指针对象的独立性
> **用已有指针的值初始化另一个同类型指针对象，会建立一个独立的指针对象，并为它保存一份相同的指针值。**当复制的是指向某个对象的值时，两个指针起初指向同一个目标；目标对象没有因此被复制，各指针对象仍各自保存自己的值。

## 多条路径与同一个对象

多个名称或表达式指定同一个对象时，它们之间存在别名关系（aliasing）。需要分清指针对象自身，以及沿着指针指定的目标：

| 表达式 | 指定的对象 | 对象类型 |
| --- | --- | --- |
| `target` | 指针对象 `target` | `int*` |
| `alias` | 另一个指针对象 `alias` | `int*` |
| `value`、`*target`、`*alias` | 同一个目标对象 `value` | `int` |

`target` 与 `alias` 是两个不同的对象，只是当前保存相同的指针值。`value`、`*target` 与 `*alias` 则是指定同一个 `int` 对象的三条路径。

接续上例，通过 `alias` 修改目标：

```cpp
*alias = 9;
```

赋值修改的是 `value`，所以之后读取 `value`、`*target` 或 `*alias`，取得的都是当前整数 `9`。两个指针保存的指针值均未改变；两条间接访问路径接触的是同一份状态。

> [!IMPORTANT] 别名关系与共同目标
> **别名关系取决于访问路径是否指定同一个对象。**在目标有效且允许相应访问时，通过一条路径修改对象，会影响之后经其他路径对这个对象的读取。指针对象可以彼此独立，而它们的解引用表达式指定同一个目标。

当两处代码需要共同访问同一个对象时，复制指针值可以分别保留访问路径；若要保留某一时刻的数值，则应另存一份独立数值。

## 重新指向只改变指针对象

指针对象允许赋值时，可以让它保存指向另一对象的指针值。这种关系变化常称为重新指向（reseating）。接续上例，给原来的 `target` 重新赋值：

```cpp
int other{20};
target = &other;
```

赋值的左操作数是 `target`，因此被改变的是这个指针对象。`alias` 没有接受赋值，仍然保存初始化时从 `target` 复制的指针值，继续指向 `value`。

比较 `target = &other;` 执行前后的状态：

| 对象 | 重新指向前 | 重新指向后 |
| --- | --- | --- |
| `value` | 保存整数 `9` | 仍保存整数 `9` |
| `other` | 保存整数 `20` | 仍保存整数 `20` |
| `target` | 指向 `value` | 指向 `other` |
| `alias` | 指向 `value` | 仍指向 `value` |

> [!IMPORTANT] 重新指向的作用对象
> **给可赋值的指针对象保存新的指针值，只改变这个指针对象的指向关系。**先前复制过其值的其他指针不会跟随改变；重新指向本身也不会修改原目标或新目标的值。复制取得的是复制发生时的指针值，不会建立持续跟随关系。

两条间接访问路径现在分别通向不同的对象。继续执行：

```cpp
*target = 30;
*alias = 11;
```

第一条赋值把 `other` 改为 `30`，第二条把 `value` 改为 `11`。此后读取 `*target` 得到 `30`，读取 `*alias` 得到 `11`。`value` 与 `*alias` 仍指定同一个对象；`other` 与 `*target` 指定另一个对象，`*target` 与 `*alias` 之间已经没有先前的别名关系。

判断一个对象可能在哪里被修改，需要同时考虑能够指定它且允许修改的访问路径。可修改的别名越多，需要跟踪的路径就越多，因此每条指向关系都应有明确的用途和使用范围。
