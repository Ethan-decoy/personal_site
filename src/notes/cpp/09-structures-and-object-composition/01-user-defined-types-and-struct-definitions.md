# 用户定义类型与结构体定义（User-Defined Types and Struct Definitions）

绘图程序需要记录一个点在画面中的位置。在这个程序中，`x` 表示横向位置，值越大越靠右；`y` 表示纵向位置，值越大越靠下。两个数共同确定一个位置。

先分别保存这两个数，下面的片段放在 `main` 函数体内：

```cpp
const int x{20};
const int y{10};
```

这两个数描述同一个点，但上面的声明只创建了两个独立的整数对象。要为多个点分别保存位置，可以先定义一种类型，规定一份位置包含横向和纵向两个分量，再用它创建各自的位置对象。

## 用 struct 定义一种类型

C++ 可以使用 `struct` 定义用户定义类型（user-defined type），把相关数据的组成写入一种新类型。下面的定义放在 `main` 之前；后面的对象创建片段沿用它，与开篇片段分开使用：

```cpp
struct position {
    int x;
    int y;
};
```

`struct` 是定义结构体时使用的关键字，`position` 是新类型的名称。花括号中的两条声明分别给出成员的类型和名称，这些用于保存数据的成员称为数据成员（data member）。例如，`int x;` 规定这种类型的对象包含一个名为 `x` 的 `int` 成员。

> [!IMPORTANT] 类型定义与对象创建
> **结构体定义描述一种类型，用这种类型定义对象，才会建立具体的数据。**上面这条只定义 `position` 类型的声明，没有同时创建任何 `position` 对象；同一个类型定义可以用于创建多个对象。

> [!WARNING] 独立类型定义末尾的分号不能省略
> 本例中，成员声明末尾的分号结束各自的成员声明，右花括号后的分号结束整条独立类型声明。最后一个成员的分号不能代替 `}` 后的分号；漏写后者会使这条声明不完整，编译器会诊断错误。

## 用同一种类型创建不同对象

保留上面的类型定义，把下面的片段放在 `main` 函数体内。`position` 和 `int` 一样，可以作为对象声明中的类型名称：

```cpp
const position first{20, 10};
const position second{60, 10};
```

`first` 与 `second` 分别保存两个点的位置。这里两份位置只用于读取，因此用 `const` 表明初始化后不再修改。

对本例的简单结构体，第一项 `20` 用于初始化 `first` 中的 `x`，第二项 `10` 初始化其中的 `y`。`second` 采用相同的对应方式，但横向位置的初值为 `60`。

> [!IMPORTANT] 本例的初始化器与成员顺序
> **对这里仅包含两个整数数据成员的简单结构体，花括号中的初始化器按成员声明顺序对应各成员。**本例依次对应 `x` 和 `y`；这种位置对应关系由类型定义中的成员顺序决定。

两次对象定义完成后，各自保存的数据是：

| 对象 | `x` | `y` |
| --- | ---: | ---: |
| `first` | `20` | `10` |
| `second` | `60` | `10` |

两次定义使用同一种位置结构，却分别创建自己的对象。类型中的一条 `x` 成员声明，会在每个实际创建的位置对象中对应各自的整数成员。

> [!IMPORTANT] 同一类型与独立对象
> **同一种类型可以创建身份独立的多个对象，本例中每个对象分别保存自己的横向和纵向位置。**类型相同、成员名称相同，不会让这些对象共用一份位置数据；即使两个分量的数值都相同，它们仍可以是不同对象。

现在用 `first` 就能指定第一个点的整份位置，用 `second` 指定另一个点的位置。新类型规定位置由哪些分量组成，各对象则分别保存具体数值。

## struct 定义的是类类型

`position` 的两个成员类型都是 `int`，`position` 自身则是一种类类型（class type）。

> [!IMPORTANT] struct 与类类型
> **使用 `struct` 定义的类型属于类类型。**`struct` 是定义时使用的关键字，“类类型”是定义所得类型的分类。因此，结构体对象也是类类型对象。

## 结构体内部形成类作用域

结构体定义引入类作用域（class scope）。前面的 `x` 和 `y` 都是在 `position` 类作用域中声明的成员名称。

下面是另一个独立的完整程序，将成员名称 `x` 与 `main` 中的普通变量名称 `x` 放在一起比较；不与前面的片段拼接：

```cpp
struct position {
    int x;
    int y;
};

int main() {
    const int x{20};
}
```

两处都使用名称 `x`，但声明的内容不同：

| 声明位置 | 声明的含义 |
| --- | --- |
| `position` 的类体中 | 规定这种类型的对象包含一个名为 `x` 的 `int` 数据成员 |
| `main` 的函数体中 | 创建一个独立的 `const int` 对象，初值为 `20` |

这两个名称属于不同作用域，不发生冲突。这个程序只创建了 `main` 中的整数对象，没有创建 `position` 对象，因此也没有创建某个位置中的 `x` 成员。

> [!IMPORTANT] 成员名称与访问归属
> **本例的数据成员名称在类作用域中声明，实际数据属于具体的结构体对象。**读取或修改这些成员时，要确定其所属对象；`struct` 中没有另行指定访问权限的成员默认为公有（public），允许从类外访问。是否允许修改，还须满足对象及当前访问路径的 `const` 约束。

把普通赋值语句直接放进类体，会发生编译错误。下面的错误定义用于替换上面完整程序中的类型定义：

```cpp
struct position {
    int x;
    int y;
    x = 35; // 错误：不能把普通赋值语句直接写在类体中
};
```

> [!WARNING] 类体不是普通执行语句块
> `int x;` 在这里声明数据成员，没有创建可立即赋值的某个位置对象。把普通赋值语句直接放在类体中，不符合这里的成员声明语法，编译器会诊断错误；它不会在定义类型时修改某个位置对象。对具体位置的修改需要放在函数体等执行代码的位置，并通过相应对象进行。
