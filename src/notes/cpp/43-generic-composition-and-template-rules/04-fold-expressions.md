# 折叠表达式与组合次序（Fold Expressions and Combination Order）

包展开可以生成一组调用实参；要用同一运算组合一组值，还需要指定运算的结合结构。折叠表达式（Fold Expression）将参数包逐项组成表达式。

## 初始值确定空包和结果起点

`(0 + ... + values)` 是带初始值的左折叠，展开为 `((0 + v1) + v2) ...`。下面只接受 int，避免把类型混合隐藏在加法中：

```cpp
#include <concepts>
#include <iostream>

template <typename... Values>
    requires(std::same_as<Values, int> && ...)
constexpr int total(Values... values) {
    return (0 + ... + values);
}

int main() {
    std::cout << total() << '\n';              // 0
    std::cout << total(220, 230, 240) << '\n'; // 690
}
```

约束中的 `&&` 也是折叠，要求每一项类型都满足同一条件。空包的该条件为真。数值例子选择可表示的总和；模板和折叠都不自动防止整数溢出。

没有显式初始值的空包折叠只有部分运算符有规定结果：`&&` 为 true，`||` 为 false，逗号为无值结果。空的纯加法折叠不合法。

## 结合方向不等于求值先后

左折叠和右折叠决定括号结构。减法、浮点加法或自定义运算中，结构可以改变结果；不能只因为运算符形状相同就假定可重新结合。

沿用 total 的 `Values... values` 形参，把返回表达式换成下面两种无初值的减法折叠，并传入相同的三项 `220、230、240`：

| 返回表达式 | 本次展开的括号结构 | 结果 |
| --- | --- | ---: |
| `(... - values)`，左折叠 | `(220 - 230) - 240` | `-250` |
| `(values - ...)`，右折叠 | `220 - (230 - 240)` | `230` |

左折叠先把前两项组合成 `-10`，再减去 240；右折叠先把后两项组合成 `-10`，再由 220 减去它。值的次序和运算符都相同，括号结构已经改变了结果。这里三个数都在可表示范围内，也没有副作用；这两种无初值的纯减法折叠不能接收空包。

求值顺序还取决于运算符规则。内建逗号、`&&`、`||` 有相应顺序或短路关系；加法的左结合不能据此保证各操作数中的副作用从左到右执行。

> [!TIP]
> 分别检查空包结果、展开后的括号结构、运算符求值规则和数值范围。折叠节省重复语法，不替组合关系提供交换律或结合律。
