# C++ 全书结构与覆盖

用于规划新章、调整分篇和审阅全书覆盖。当前核对范围为第 00–27 章，语言基准为 C++23；篇章写法遵循 [writing-style.md](./writing-style.md)。新增知识主线后同步更新覆盖与近期方向。

## 现有分篇

分篇表示连续阅读阶段，保留现有章号、正文路径和顺序；同一设施可以在不同阶段承担不同问题。

| 分篇 | 章节 | 已建立的主线 |
| --- | --- | --- |
| 01 · 语言与程序基础 | 00–06 | 编译与执行、对象和基本类型、表达式、作用域、控制流、函数、常量与转换 |
| 02 · 对象访问与类接口 | 07–11 | 指针与引用、对象组合、封装与构造、序列访问与存储变化 |
| 03 · 重载与类型转换 | 12–14 | 候选函数选择、运算符接口、用户定义转换与显式边界 |
| 04 · 复制、移动与资源管理 | 15–19 | 复制与赋值、析构、移动、异常传播、动态对象与独占所有权 |
| 05 · 数据组织与处理 | 20–27 | 连续范围、文本、迭代器与算法、Lambda、排序、可选值、有序与无序映射 |

例如，第 11 章用 `vector` 建立序列访问，第 20 章用 `array`、`span` 区分固定长度与连续借用；分篇不按容器名称重新聚类。公开概览保持导航职责，未写方向保留在本文件。

## 能力覆盖与依赖

“已有”指正文实际建立的范围；使用过某个设施，不等于已经展开其完整机制。下表记录主要缺口，不要求每行独立成章。

| 能力 | 已有范围 | 待展开的问题与依赖 |
| --- | --- | --- |
| 名称与程序组织 | 00 的翻译单元、分别编译与链接；03 的局部名称查找；05 的声明与定义；`std::` 使用契约 | 命名空间、限定查找、`using`、用户头文件、重复包含、跨文件定义与链接属性。再建立单一定义规则、`inline` 和静态存储对象的初始化关系；模板中的名称查找接在泛型基础之后。 |
| 常用类型与接口补全 | 基本类型、聚合与类接口；多种初始化形式、窄化和 `explicit` 边界 | 枚举表达有限状态，类型别名表达已有类型，静态成员与局部静态对象表达共享状态；默认实参和结构化绑定按接口需要接入。列表初始化的重载选择与 `initializer_list` 接口需要结合构造、重载和模板补齐。 |

| 可调用接口 | 普通函数、函数对象、Lambda 及捕获生命周期 | 函数类型与函数指针、统一保存不同可调用对象、调用包装的所有权和开销。函数指针依赖函数和指针；类型擦除的使用契约与实现机制分层安排。 |

| 资源共享 | 动态对象、`unique_ptr` 与借用 | 共享所有权、弱引用与循环引用，扩展现有资源模型；区分共享生命周期与并发访问对象的安全性。 |

## 近期构建方向

1. **名称与多文件程序。** 从命名空间及名称归属进入，再构建自己的头文件、跨文件声明与定义。分清名称可见性、实体身份与存储期，为模板定义的组织提供基础。
2. **从使用模板走向编写模板。** 以已有函数和类的重复逻辑为入口，建立函数模板、类模板和推导；再进入泛型接口约束及转发。需要的别名等基础设施就近建立，避免仅因已写多种容器而继续扩展容器目录。
3. **扩展对象与计算模型。** 运行时多态、编译期计算分别形成主线；输入输出、数据建模和可调用包装按所需依赖接入。高级名称查找、特化等在具体泛型问题出现时展开。

这些是能力方向，不预定远期章号或篇幅。选定新章时核对其前置模型、补齐的能力和当前主线的停止边界；相邻章节能自然引出某个话题，只是选题依据之一。

## 后置与未定项

- **精细对象模型：** 现有附章已涉及布局、对齐、原生数组、分配和构造；存储复用、对象表示访问、联合体活跃成员、自定义分配按需求继续下钻。
- **工程组织与验证：** 模块、构建系统、断言、诊断与调试、测试与分析工具、接口的二进制兼容和 C 互操作，按相应语言模型接入；断言可结合不变式提前建立，涉及平台的行为单独标明前提。
- **专门库与语言设施：** 位操作、时间、随机数、数值计算、正则表达式、其他容器与适配器等，按独立问题决定是否展开。遗留模板技巧用于解释已有代码时补入，不作为现代泛型入门前提。
