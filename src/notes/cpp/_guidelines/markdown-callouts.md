# Markdown 提示块

用于突出 C++ 笔记中的查阅重点。内容取舍遵循 [写作规范](./writing-style.md)。

```markdown
> [!IMPORTANT]
> 需要强调的结论。
```

- 默认省略标题；需要时在标记后加具体标题，不重复类型名称。
- 块内使用普通 Markdown，每行（含空行）保留 `>`。
- 类型、篇幅、数量和位置按内容需要选择。

| 标记 | 用途 |
| --- | --- |
| `[!IMPORTANT]` | 核心关系或结论 |
| `[!TIP]` | 判断依据、选择条件或步骤 |
| `[!PRACTICE]` | 工程用法与设计取舍 |
| `[!WARNING]` | 易错边界及后果 |
| `[!NOTE]` | 背景或补充说明 |
| `[!CAUTION]` | 操作风险 |

`PRACTICE` 是本站扩展。调整视觉时参照 [设计规范](../../../../docs/DESIGN.md#24-markdown-文档排版)。
