# Markdown 提示块

用于按内容职责突出 C++ 笔记中的重点。内容取舍遵循 [写作规范](./writing-style.md)；熟记、理解与查阅内容的区分，参照其中的 [掌握要求](./writing-style.md#掌握要求)。

```markdown
> [!IMPORTANT] 静态链接与动态链接怎样提供实现
> **静态链接把所需实现并入输出产物；动态链接让相应实现保留在独立动态库中，启动或运行时仍需加载它。**
```

- `[!IMPORTANT]` 蓝色提示块用于需要熟记的核心关系，在讲解建立该关系的位置就地呈现，并保留适用条件与判断用途；文末回顾不代替就地突出。
- 蓝框本身已表明掌握要求，标题直接写对象、问题或关系，不加“需要熟记”“重点记忆”等前缀，正文也不重复这些标签。标题使用普通文本，由现有样式突出，不额外添加加粗或行内代码标记。
- 其他类型可以省略标题；需要帮助定位时，在标记后加具体标题，不重复类型名称。
- 块内使用普通 Markdown，每行（含空行）保留 `>`。
- 类型、篇幅、数量和位置按内容需要选择。

| 标记 | 用途 |
| --- | --- |
| `[!IMPORTANT]` | 需要熟记并能直接调用的核心关系或结论 |
| `[!TIP]` | 判断依据、选择条件或步骤 |
| `[!PRACTICE]` | 工程用法与设计取舍 |
| `[!WARNING]` | 易错边界及后果 |
| `[!NOTE]` | 背景或补充说明 |
| `[!CAUTION]` | 操作风险 |

`PRACTICE` 是本站扩展。调整视觉时参照 [设计规范](../../../../docs/DESIGN.md#24-markdown-文档排版)。
