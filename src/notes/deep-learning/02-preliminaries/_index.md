# 预备知识

本章介绍实现和训练模型时会用到的数据操作与数学工具。

## 阅读顺序

1. [数据操作](01-data-manipulation.md)
2. [数据预处理](02-data-preprocessing.md)
3. [线性代数](03-linear-algebra.md)
4. [微积分](04-calculus.md)
5. [自动微分](05-automatic-differentiation.md)
6. [概率](06-probability.md)

## 学习目标

- **准备数据并读懂张量运算。** 本章用表格举例，行对应样本，列对应属性。练习读入数据、处理缺失值并转成张量，再根据各轴的长度判断常见矩阵运算的输入和输出形状。
- **理解梯度怎样用于训练。** 在常见的梯度训练中，微积分解释给定的训练目标如何随参数变化，框架通过自动微分计算梯度，优化算法利用梯度更新参数。
- **用概率描述不确定性。** 读懂基本的概率表述，并用条件概率描述给定观测后各种结果的可能性。

想进一步理解线性代数、微积分和概率的推导，可以按主题查阅[原书数学附录（英文）](https://d2l.ai/chapter_appendix-mathematics-for-deep-learning/index.html)。
