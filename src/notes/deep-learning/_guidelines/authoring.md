# 深度学习内容维护与验证

用于新内容接入、原书整理、已有正文修饰和交付。规范分工见 [book-structure.md](book-structure.md#定位与规范分工)；本文件维护文件接入、来源与验证约定。

## 内容接入

本分类复用现有笔记目录、按篇加载、搜索、引用速览和代码控件。公开入口为分类 `_index.md`；一章有多节时采用章目录与 `_index.md`，正文按当前学习问题组织。节序由实际章索引维护，文件编号与 `order` 用于排序。

编号章的索引 `title` 沿用 C++ 和 Python 的「两位章号 · 章名」格式，例如 `01 · 引言`。章号与目录编号对应。正文一级标题和分类概览中的章节链接使用章名，章内各篇使用主题名。

章内阅读目录使用 Markdown 有序列表，从 `1.` 开始按阅读顺序逐篇列出链接。列表序号表示本站章内的阅读位置。

公开文件填写 `title`、`date`，按需填写 `order`。公开目录只收录已有内容；作者规范留在 `_guidelines/`，来源和分节映射留在 `_sources/`，其他草稿按需放在下划线目录。内部材料不进入公开目录、搜索或生产正文，公开内容不链接私有规范。

迁移、拆合或改标题时同步分类与章索引，核对引用、图表归属和知识前置。概念回指使用实际正文与锚点，目录入口链接全文。已有无关正文、研究与草稿保持各自范围。

## 来源与适配

原作者、原书入口、固定源码快照和实际许可集中保留在[分类的来源与许可](../_index.md#来源与许可)。正文保留知识引用与必要的跨章入口，逐篇不附讨论、原文和来源许可落款。

首次迁移核对正文、例子、公式、图表、小结与练习的范围。表达修饰保留原意与推理条件；结构化记录区分首次迁移、分节、图文改编和实质解释或代码变更，不为每次加粗、换行追加修改日志。现有记录见[引言来源与适配](../_sources/introduction.json)。

时效性更新按[写作规范](writing-style.md#时效性与知识更新)取舍。在 `_sources/` 记录实际核对日期、涉及正文、修改理由和支持具体判断的一手来源；来源的发表时间与读取的版本可辨认。固定迁移快照及其原始计数继续保留，后续修订单独记录；公开来源说明同步反映实际适配范围，局部核对不宣称整章事实已全面更新。

保留原图或代码时沿用其来源关系；新增、重绘或替换资源核对必要归属。历史表述与当前接口事实按实际时间和版本区分，校正疑点或形成新技术结论时核对相应一手资料，并保存支持实质改动的依据。

## 图文资源

公开资源位于 `public/assets/notes/deep-learning/`，通过本站基础路径接入。优先保留可编辑源和适合网页阅读的格式、尺寸与体积；避免重复母版及未引用的公开资源。图片的固有尺寸、延迟加载、解码与图组接入按[站点排版](../../../../docs/DESIGN.md#24-markdown-文档排版)维护。

图文内容和显示核对按 [illustration-style.md](illustration-style.md)执行。修改共享的渲染、容器或主题规则时同步 `docs/DESIGN.md`，保留对应渲染检查；局部内容修饰使用已有排版能力。

## 示例与实验验证

验证与正文声称的关系对应，记录实际数据、依赖、设备及当前需要的初始状态：

| 对象 | 应核对的证据 |
| --- | --- |
| 公式与手算例子 | 符号与范围、运算维度、等式或近似条件、关键中间量与结果 |
| 完整脚本或片段 | 从声明的初始状态运行，核对数值、形状、修改效果和必要输出；片段有可重建的外壳 |
| Notebook 或交互记录 | 按声明顺序执行，名称、模型、梯度与文件状态来源可追踪 |
| 预期失败与对照 | 单独确认触发条件、失败行为或区别，独立对照恢复相应初始条件 |
| 训练与实验图 | 数据划分、预处理、配置、随机性、统计口径与图表对应；结论限于验证范围 |
| 性能与设备结论 | 测量对象、规模、运行条件和计时范围；涉及异步设备时核对必要同步 |
| 纯文本与示意数据 | 标注、顺序、对应关系与正文一致，明确其示意用途 |

小样本跑通、完整训练和重复实验支持的结论不同，按实际声称的范围选择验证。来源输出、文档核对、手算、程序实跑和性能测量分别记录；未完成的验证明确说明，不用网站构建代替实验。

## 审阅与交付

按本次范围阅读完整正文和全部适用规范。依据具体位置检查范围、解释、重点遗漏、提示块取舍、图文对应和证据；语言、历史或概览材料按其用途判断，条件不适用时说明理由。

审阅默认在聊天中交付问题、建议与限制；修订按用户的任务范围实施。阅读源码、检查最终显示和执行实验分别说明，审阅结果不扩大到尚未验证的范围。

- 改动正文链接或标题后运行 `pnpm check:deep-learning-links`，验证实际渲染的站内锚点。
- 新增、迁移、删除正文或调整目录后运行 `pnpm build`，覆盖链接、侧栏、搜索、分包、性能预算与私有目录隔离。完整构建通过后，不重复执行相同检查。
- 新增或修改内部规范时，另行核对规范自身的相对链接与实际标题锚点，确认内部内容仍被排除；公开笔记链接检查不覆盖这些文件。
- 修改图文或交互后完成相应的最终显示检查；验证只覆盖检查实际观察到的性质。
