## 定位与规范分工

以《动手学深度学习》中文版为教材主线，兼顾顺序理解与回顾查阅。原书已经建立的解释、推导和例子是整理基础；修饰的目标是让核心关系更容易定位，让文字、公式、图示和实现能够互相对应。

沿用语言笔记按结构、写作、代码与维护分工的框架，为深度学习增加独立的图文规范。本分类保留原书的小结与练习，具体范围按当前学习内容决定。

| 当前任务 | 主要依据 |
| --- | --- |
| 确定章节职责、前置与分节边界 | 本文 |
| 修饰正文、提炼重点、选择提示块与审阅表达 | [写作与重点呈现](writing-style.md) |
| 选择、重绘或审阅图示、数值图与交互演示 | [图文与可视化](illustration-style.md) |

这些文件分别维护各自的约定；站点排版与组件行为由 [Markdown 文档排版](../../../../docs/DESIGN.md#24-markdown-文档排版)维护。

## 与相邻分类的关系

- Python 笔记建立语言与必要工具基础。深度学习正文就近解释当前用到的符号与写法，语言细则回指其主要讲解位置。
- PyTorch 笔记建立张量、模块、梯度与运行状态的框架使用能力。深度学习正文负责模型为什么这样定义、目标如何建立、计算与训练为何有效，以及结论的条件。
- 计算机视觉等应用分类承载各自的领域问题。本分类中的任务与数据用于建立当前深度学习模型；已有解释通过具体小节连接，必要的当前前提仍在使用处恢复。

同一概念在不同任务中可以适量回顾，按本次判断需要恢复联系，保持各分类的主要解释职责清楚。

## 分节与内容归属

每节围绕一个可以辨认的问题组织。同一问题中紧密依赖的关系可以合讲；拆分以降低理解负担为依据，不按术语数量或字数配额切分。既有分节可以调整，并非后续章节的固定模板。

主线保留当前判断所必需的条件、例子和推理。附章在具备前置后展开更细的机制或旁支；索引定位阅读关系，标题足以导航时保持简洁。原书的练习与叙述不因其他分类的写作选择而自动删去。

拆分后核对例子的上下文、符号定义、图表和回指是否仍可追踪。章节内连续阅读可以承接前文；单篇缺少必要前提时，用最短的解释恢复当前关系，并链接实际讲解位置。
