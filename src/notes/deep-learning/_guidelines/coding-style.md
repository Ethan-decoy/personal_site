# 深度学习代码示例规范

用于原书代码整理、自编实现及其输出和配套解释。知识层次见 [writing-style.md](writing-style.md)，执行验证见 [authoring.md](authoring.md#示例与实验验证)。

## 实现选择

新增的框架实现默认采用 PyTorch，有对应的站内框架笔记时就近引用。需要比较其他框架或保留原例时，按当前问题选择并说明环境。Python 与框架版本按接口、平台和依赖的兼容性确定，分别记录来源快照与实际运行环境。

从零实现用于看清模型计算、目标或更新关系；高级接口用于表达已经建立的机制与实际用法。比较两者时保持数据、目标、归约、参数与更新约定可对应，不能只凭输出形状相同认定实现等价。

辅助函数可承载下载、绘图和已经建立的重复操作。当前正在解释的计算或训练步骤，应在可见代码或明确链接的实现中可追踪；`d2l` 等辅助接口的作用和必要状态在使用处交代。

## 表达与数学对应

Python 的布局、命名与代码块形式沿用 [Python 代码示例规范的格式与名称](../../python/_guidelines/coding-style.md#格式与名称)，导入按其[源文件与依赖](../../python/_guidelines/coding-style.md#源文件与依赖)核对。数学对照可以保留已定义的短名和惯用符号，说明它们与样本、参数或中间结果的对应。

公式涉及的轴、形状、批次、归约、常数因子和参数更新方向，应与实现一致。长表达式可以拆成有含义的中间量；手写循环与张量算子按当前解释目的选择，保留广播、修改和梯度关系。

完整脚本、接续片段、Notebook 与交互记录分别交代入口和初始状态。文本对齐或示意输出使用 `text`，与可执行程序区分；注释说明当前不易直接看出的条件和选择原因。

## 数据、梯度与模型状态

按示例实际用到的张量与共享存储、数据与模块、梯度与训练循环、保存与恢复核对状态与接口。对应的框架用法见 [PyTorch 基础教程](https://docs.pytorch.org/tutorials/beginner/basics/intro.html)。

就当前示例保持以下关系可追踪：单样本与批次的表示、标签与损失输入、训练与评估的数据职责、梯度清理与累积、参数更新、模式切换以及保存范围。推理、记录梯度与参数更新分别说明，额外复制、重新初始化或关闭梯度应有实际用途。

## 示例与实验结论

解释机制优先采用小到足以手算或逐步核对的数据；真实数据与完整训练用于支持相应的学习或性能结论，保留原例所需规模的依据。

一次运行验证所声明的关系。能执行、输出形状正确、损失下降、泛化改善和性能更高是不同结论，应分别有对应证据；代码输出、图表与正文使用同一组条件。随机或设备相关结果只声称已验证的稳定性质。

来源日志与本站实跑结果分别标明。验证方式和证据保存由[维护与验证](authoring.md#示例与实验验证)规定，网站构建不执行 Python 示例。
