# 深度学习图文与可视化规范

用于选择、制作、重绘和审阅深度学习图文。重点取舍与提示块职责由 [writing-style.md](writing-style.md)维护；资源接入与来源记录见 [authoring.md](authoring.md)。

## 图文分工

图文应减少理解当前关系所需的追踪与换算。先确定要显现的对象、联系或变化，再决定形式：

| 形式 | 适合回答的问题 |
| --- | --- |
| 局部强调或提示块 | 当前最需要记住、区分或核对的关系是什么 |
| 对照表 | 哪些条件、输入输出、标签或状态需要逐项比较 |
| 结构图与流程图 | 数据、模型、目标或环境之间有什么联系 |
| 连续状态或分步图 | 某次计算、参数更新或信息传递具体改变了什么 |
| 坐标图与数值图 | 数量如何变化，尺度、趋势或分布有什么意义 |
| 原图、照片与界面截图 | 具体对象、历史材料或实际应用输出是什么样子 |

照片与截图可以保留其叙述用途；讲解内部机制时，应有相应的关系或过程依据。简短正文已说清的内容，无需再换成相同信息的图、表和框。

## 原图与新增图示

先判断原图是否承担正文尚未清楚呈现的解释作用。只重复简短定义或输入输出清单的图，可以移除；能帮助追踪结构、计算与反馈的图，按实际问题保留或重绘，并维护来源和改编关系。

概念与机制示意图优先适配本站的明暗主题，文字、连接和强调随阅读区模式切换。历史照片与界面截图可保留原始外观；其原色或白底不作为机制图默认沿用的理由。

新增教材图默认采用可编辑的静态 SVG，数值曲线与实验图按明确的函数或数据生成。图的数量和复杂程度由解释需要决定；新增图应能指出它帮助追踪的具体关系。

交互用于观察参数、输入或步骤变化确有理解收益的情形。提供当前取值与结果、可辨认的控制和重置方式，并保留静态阅读入口；自动播放不能成为理解的唯一途径。新增交互的键盘操作、减少动态效果与按需加载须一并核对。

## 对象与计算关系

- 图、文、公式与代码沿用一致的名称、符号和值；改变表示时写清对应关系。示意样本与真实实验数据分别标明。
- 箭头明确表示数据流、计算依赖、梯度、参数更新还是环境反馈；同一图中的不同含义应通过标注或线型区分，端点连接实际对应的对象。
- 训练与使用模型的过程分别表示，参数是否发生变化可追踪。数据、预测、目标与损失不能因排版方便被画成同一种对象。
- 张量、卷积与注意力等图示，标明当前解释需要的轴、索引、形状与运算方向。省略维度或只画局部时，保留简化条件。
- 分步图保持同一对象的身份与位置可辨，强调对应本步实际变化；前后数值与状态应可由正文或运算得到。
- 类比图与抽象层次图表明解释范围，图上的空间位置、连线或命名不自动构成模型机制的额外保证。

## 数值图与实验图

坐标、单位、尺度、图例与比较条件应可辨认。概念曲线说明其示意性质；计算曲线保留生成关系，实验曲线保留数据和测量条件。调整坐标或裁切不应掩盖当前结论所依赖的变化。

比较损失、准确率、参数或训练轨迹时，说明统计对象与聚合口径。示例数值应与对应公式、代码和显示步骤一致；视觉上的相关、接近或分离，不能单独代替相应的技术结论。

## 视觉层次与主题

图内保留识别对象、方向与变化所需的标注，解释性长文放在正文。图注说明当前图组的主题和必要条件，替代说明保留核心含义。图例与图共同提供，含义不只依赖颜色。

新绘教材图的图面、文字、连接与强调层级遵循[教材示意图的视觉基准](../../../../docs/DESIGN.md#教材示意图的视觉基准)。同一组图的颜色与符号含义稳定，深浅主题保持相同的关系。

嵌入正文的小幅机制图可采用透明图面，文字与节点色值对应 `src/themes.ts` 的 Notes 配色。复用图组容器的 `color-scheme` 传递，在当前图组内按需取消底色、外框和最小阅读宽度；以实际尺寸确认标注仍清楚，避免影响其他图组。

共享图组的容器、主题传递、固有尺寸、加载与窄屏查看按 [Markdown 文档排版](../../../../docs/DESIGN.md#24-markdown-文档排版)接入。简单图片依信息量保留固有阅读尺寸；复杂图需要更多空间时采用图组或分步布局。窄屏无法清楚缩放时，优先重排、拆图或提供图内横向查看，保持正文可读。

## 交付与审阅

图文修订应分别完成语义核对与显示核对：

- 语义上逐一检查对象、连接、计算、数值、时间或状态顺序，以及图文代码的对应；必要的简化与比较条件没有丢失。
- 查看最终渲染结果，检查文字、图例、箭头、裁切和留白；核对正文宽度、窄屏、明暗主题，以及站内模式与系统偏好不同的情况。
- 有交互时核对状态变化、控制与结果、键盘使用、重置和静态阅读方式；资源与运行成本保留实际测量范围。

自动检查没有报溢出，不代表标注已经清楚。交付说明区分文本与语义审阅、实际渲染和交互验证，未检查的部分明确保留。
