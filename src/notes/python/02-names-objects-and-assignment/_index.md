2. [对象的类型](02-object-types.md)：区分值、类型与显示结果，理解重新绑定与对象类型的关系，并依据实际类型判断操作。
3. [对象身份与相等比较](03-object-identity-and-equality.md)：区分相等与同一对象，追踪重新绑定后的身份关系，并辨认对象复用与 None 判断的边界。
4. [对象修改与共享引用](04-mutation-and-shared-references.md)：区分原地修改与名称重新绑定，理解对象可变性，并分别判断方法的修改效果与返回值。
5. [列表的浅复制](05-shallow-list-copies.md)：区分外层列表的独立与元素对象的共享，按实际修改对象判断复制范围。
