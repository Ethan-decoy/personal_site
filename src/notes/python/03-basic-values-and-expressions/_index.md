# 基本值与表达式

本章从整数与浮点数开始，建立数值表示、算术、比较与布尔运算的规则，并区分字符串的源码写法、实际内容与显示形式。

1. [整数与浮点数](01-integers-and-floating-point-numbers.md)：辨认数值写法，推演混合加法，并理解有限表示与舍入。
2. [算术运算与表达式求值](02-arithmetic-and-expression-evaluation.md)：判断算术结果的值与类型，区分商余规则、表达式分组与求值先后。
3. [比较运算与布尔值](03-comparisons-and-boolean-values.md)：理解数值比较、结果绑定、类型条件与链式比较的短路求值。
4. [真值测试与布尔运算](04-truth-value-testing-and-boolean-operations.md)：判断已学对象的真值，追踪布尔运算的结果对象、短路求值与表达式分组。
5. [字符串字面量与转义](05-string-literals-and-escape-sequences.md)：区分字面量写法、字符串内容与表示形式，理解转义、多行文本与原始字符串的引号边界。
6. [格式化字符串与数值显示](06-formatted-strings-and-numeric-display.md)：理解替换字段的求值与结果保存，用表示形式和数值格式说明生成所需文本。
7. [数值转换与文本解析](07-numeric-conversion-and-text-parsing.md)：区分文本解析与数值转换，判断结果绑定、向零截断、浮点精度与范围边界。
