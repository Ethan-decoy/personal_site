# 列表切片（List Slicing）

[单项索引](01-lists-length-and-indexing.md#整数索引与负数位置)取得某一个位置上的元素，列表切片则按区间与步长选取一组位置，返回保存所选元素引用的新列表。选中零个、一个或多个元素，结果都仍然是列表。

本篇讨论内置列表的切片读取，起止边界与步长主要采用整数或省略形式。各个 `python` 代码块都是独立的完整脚本，分别在 Windows 64 位 CPython 3.14.10 中核对；预期失败的脚本也单独运行。

## 切片写法与选取结果

切片（slicing）的基本写法是 `values[start:stop]`。冒号分隔起始边界与终止边界；默认步长为一，索引从起点逐一增加，到终点之前停止。对于合法的非负边界，所选索引满足 `start <= index < stop`，这种包含起点、不包含终点的区间称为半开区间（half-open interval）。

```python
values = [30, 10, 20, 40]
part = values[1:3]

print(values[1])
print(part)
print(values[1:2])
print(type(part))
```

输出为：

```text
10
[10, 20]
[10]
<class 'list'>
```

`values[1]` 取得整数十。`values[1:3]` 则选取索引一、二处的元素，不选取索引三处的四十，结果为列表 `[10, 20]`。`values[1:2]` 只选中一个位置，但结果仍是列表 `[10]`，不是整数十。

新列表的位置从零开始编号：`part[0]` 引用原列表索引一处的整数十，`part[1]` 引用原列表索引二处的整数二十。切片读取不会改变原列表的内容，也不在结果中保留原位置的编号。

## 省略边界、负值与越界

默认步长一从前向后选取。省略起点时从开头开始，省略终点时一直选到末尾；显式负边界则像[负索引](01-lists-length-and-indexing.md#整数索引与负数位置)一样，先按当前长度换算：

```python
values = [30, 10, 20, 40]

print(values[:2])
print(values[2:])
print(values[-3:-1])
print(values[:])
```

输出为：

```text
[30, 10]
[20, 40]
[10, 20]
[30, 10, 20, 40]
```

当前长度为四。`values[:2]` 从索引零取到索引一；`values[2:]` 从索引二取到末尾。`-3` 换算成一，`-1` 换算成三，因此 `values[-3:-1]` 与 `values[1:3]` 选取相同位置。终点处的元素始终不包含在这次选取中。

`values[:]` 的两端都省略，选取全部元素。边界也可以显式写成 `None`，表示采用相应的默认选择，例如 `values[None:None]` 与 `values[:]` 选取相同位置。

切片边界可以超出列表的实际范围。对这里的步长一，显式负边界先加上当前长度，再把边界限制在零到列表长度之间：

```python
values = [30, 10, 20, 40]

print(values[1:99])
print(values[99:])
print(values[3:1])
print([][:])
print(values[-99:99])
```

输出为：

```text
[10, 20, 40]
[]
[]
[]
[30, 10, 20, 40]
```

终点九十九被限制到长度四，`values[1:99]` 因而选取索引一、二、三处的元素。`values[99:]` 的起点与终点都调整为四，没有可选位置；`values[3:1]` 则要求从三开始向前递增，却在一之前停止，同样选不到元素。空列表的切片也可以正常得到空列表。

`values[-99:99]` 的起点先按长度换算，仍小于零，于是限制到零；终点限制到四，最终选取整个列表。这里不会像[单项索引越界](01-lists-length-and-indexing.md#索引边界与失败位置)那样引发 `IndexError`，因为切片处理的是选取区间。

> [!IMPORTANT] 正向切片的区间与越界
> **步长为一时，列表切片从调整后的起点开始，按索引递增选取，在终点之前停止。**省略起点采用零，省略终点采用当前长度；显式负边界先按长度换算，再把边界限制在零到长度之间。起点不小于终点时，结果是空列表。

## 步长、方向与默认终点

完整写法 `values[start:stop:step]` 用第二个冒号引入步长（step）。整数步长表示相邻所选索引的变化量：正值向较大的索引选取，负值向较小的索引选取。省略步长或将它写成 `None`，都采用一。

```python
values = [30, 10, 20, 40]

print(values[::2])
print(values[::-1])
print(values[3:0:-1])
```

输出为：

```text
[30, 20]
[40, 20, 10, 30]
[40, 20, 10]
```

第一行选取索引零、二，索引每次增加二。第二行从末尾向前逐个选取，生成逆序的新列表。第三行明确从索引三开始，每次减一，依次选取三、二、一；终点零不取，因此结果中没有索引零处的三十。

**省略边界的默认选择随步长方向改变。**正步长默认从开头开始，终点在最后一个元素之后；负步长默认从末尾开始，终点在索引零之前。反向省略终点表示一路选到开头，不是把终点写成末尾索引 `-1`。

显式的 `-1` 仍按当前长度换算为末尾位置，不能代替反向省略的终点。反向边界的完整换算与裁剪，见附章[切片的边界与赋值细则](deep-dives/02-slice-boundaries-and-assignment-details.md#反向边界的换算与裁剪)。

> [!IMPORTANT] 步长与默认边界
> **整数步长必须非零，符号决定选取方向，数值决定索引每次增加或减少多少；省略步长或采用 `None` 时，步长为一。**起止边界的默认选择随方向变化，终止边界不取。反向省略终点采用索引零之前的停止边界，不等于显式末尾索引 `-1`。

步长为零无法确定选取如何推进。下面是一份故意失败的完整脚本：

```python
values = [30, 10, 20, 40]
print("start")
print(values[::0])
print("end")
```

源码合法，脚本先输出：

```text
start
```

第三行在切片读取时引发 `ValueError`，错误诊断的最后一行为：

```text
ValueError: slice step cannot be zero
```

切片没有取得结果，外层 `print` 尚未执行；列表保持原状。异常未被处理，脚本终止，`end` 不会输出，先前的 `start` 仍然存在。即使源列表为空，零步长也不合法。

边界或步长的类型也必须受到支持，浮点数不会在切片时自动取整。下面这份独立脚本使用浮点起点：

```python
values = [30, 10, 20, 40]
print("start")
print(values[1.0:3])
print("end")
```

程序先输出：

```text
start
```

第三行因起点类型不受支持而引发 `TypeError`，错误诊断的最后一行为：

```text
TypeError: slice indices must be integers or None or have an __index__ method
```

本例中的浮点起点不满足接口要求，切片未能生成结果，外层 `print` 未执行，列表也没有被修改。脚本随未处理的异常终止，不再输出 `end`。`1.0` 与整数一比较相等，并不意味着它能直接承担同一种边界输入。

## 新列表与共享元素

列表切片读取创建新列表，按所选位置与顺序保存元素引用。新外层列表的元素替换，可以独立于原列表进行：

```python
values = [30, 10, 20, 40]
part = values[1:3]

print(part is values)
part[0] = 99
print(values)
print(part)
```

输出为：

```text
False
[30, 10, 20, 40]
[99, 20]
```

`part` 引用另一个列表，起初按顺序保存原索引一、二处的元素引用。`part[0] = 99` 只替换新列表自己的第一个元素引用，原列表中指向整数十的引用保持原状。这里独立的是两个外层列表保存元素引用的位置。

新列表仍保存原元素的引用，所选元素本身是可变对象时，两边仍可能共享它；修改该元素会从两边取得相应变化，与[浅复制的外层独立、内层共享](../02-names-objects-and-assignment/05-shallow-list-copies.md#外层独立与内层共享)一致。`values[:]` 选取全部位置，得到全列表的浅副本；即使结果为空，也仍创建另一个列表。

> [!IMPORTANT] 列表切片的返回契约
> **内置列表的切片读取创建新列表，按所选位置与顺序保留元素引用，不继续复制元素对象。**新外层列表的元素替换独立；共享可变元素的原地修改仍可从两边取得。`values[:]` 创建全列表浅副本，不等于让两个名称引用同一个外层列表。

切片作为赋值目标时属于原列表的修改操作，不能直接套用这里的切片读取规则。
