# 字符串的拆分与拼接（Splitting and Joining Strings）

字符串拆分（splitting）按分隔规则取得一组字符串片段，返回列表；拼接（joining）则把来源提供的字符串片段按指定间隔组成字符串结果。这些操作不改写原字符串。

各个 `python` 代码块都是独立的完整脚本，分别在 Windows 64 位 CPython 3.14.10 中核对；预期失败的脚本也单独运行。拼接来源只使用内置列表与元组。

## 按分隔符拆成字符串列表

文本 `"480,640"` 按高度在前、宽度在后的约定保存两个像素数值。`text.split(",")` 通过字符串对象取得并调用 `split` 方法，参数 `","` 指定分隔符（separator）。调用按从左到右的顺序拆分文本，将各片段放入返回的列表，匹配到的分隔符不进入片段：

```python
text = "480,640"
parts = text.split(",")

print(parts)
print(type(parts[0]))
print(text)
```

输出为：

```text
['480', '640']
<class 'str'>
480,640
```

`parts` 保存两个字符串片段，`parts[0]` 仍是字符串 `"480"`，没有自动变成整数。拆分只划分文本，不执行[数值解析](../03-basic-values-and-expressions/07-numeric-conversion-and-text-parsing.md#文本解析的格式条件)。原来的 `text` 仍保存完整文本。

字符串形式的分隔符按整段内容匹配，可以包含一个或多个字符。连续分隔符之间没有其他内容时，那里会产生空字符串；首尾分隔符也会留下对应的空片段。下表各行独立计算，结果以列表字面量表示：

| 表达式 | 结果 |
| --- | --- |
| `"480,,640,".split(",")` | `['480', '', '640', '']` |
| `",480".split(",")` | `['', '480']` |
| `"480".split(",")` | `['480']` |
| `"".split(",")` | `['']` |
| `"480<>640".split("<>")` | `['480', '640']` |

没有匹配到分隔符时，整个输入文本成为唯一片段。因此，空文本按逗号拆分得到的是包含一个空字符串的列表 `['']`，不是空列表 `[]`。

字符串分隔符不能为空。把 `""` 传给 `split` 会在运行时引发 `ValueError`：

```python
text = "480,640"
print(text)
parts = text.split("")
print("after split")
```

第三行因分隔符为空而失败。此前已经输出：

```text
480,640
```

异常末行为：

```text
ValueError: empty separator
```

调用没有返回，`parts` 尚未绑定；`text` 仍保持原文，最后一行不会执行。

## 省略分隔符时的空白规则

`text.split()` 省略分隔符，或将分隔符写成 `None`，都会采用空白拆分。空格、制表符和换行等空白字符（whitespace characters）可以分隔片段；连续的一段空白作为一个分隔，首尾空白不产生空片段。

`text.split(" ")` 则显式指定一个空格，仍按前述字符串分隔符的规则处理：

```python
text = " 480  640 "

print(text.split())
print(text.split(" "))
```

输出为：

```text
['480', '640']
['', '480', '', '640', '']
```

第一行只保留两个非空片段。第二行逐次匹配单个空格，首尾各留下一个空片段，中间两个相邻空格之间也留下一个空片段。省略参数与传入空格，选择的是不同的拆分规则。

这个区别同样决定空输入的结果。下表每行的 `text` 分别采用输入列中的值：

| 输入 `text` | `text.split()` | `text.split(" ")` |
| --- | --- | --- |
| `""` | `[]` | `['']` |
| `"   "` | `[]` | `['', '', '', '']` |

> [!IMPORTANT] 指定分隔符与默认空白拆分
> **显式采用非空字符串分隔符时，按整段分隔符拆分，保留相邻或首尾分隔符产生的空片段；省略分隔符或传入 `None` 时，按连续空白拆分，首尾不产生空片段。**空文本在两种规则下分别得到 `['']` 与 `[]`。两种方式返回的都是字符串组成的列表，不自动解析其中的数字文本。

## 用分隔符拼接字符串片段

`separator.join(parts)` 由分隔符字符串 `separator` 提供 `join` 方法，`parts` 提供待拼接的字符串。来源须是能够逐个提供元素的[可迭代对象](04-adding-and-removing-list-elements.md#追加一个对象与扩展一组元素)，并且每个元素都已经是字符串。本篇使用列表或元组，按其中的元素顺序拼接。

`" x "` 可以作为尺寸文本之间的间隔，其中字母 `x` 两侧各有一个空格：

```python
parts = ["480", "640"]
result = " x ".join(parts)

print(result)
print(parts)
```

输出为：

```text
480 x 640
['480', '640']
```

两个片段之间只插入一次 `" x "`，开头与结尾没有额外添加这个分隔符。返回的字符串由 `result` 保存，来源列表 `parts` 仍保存原来的两个元素。

空来源没有片段可拼，单项来源没有相邻片段之间的间隔，结果相应如下。表中各行独立计算，结果以字符串字面量表示：

| 表达式 | 结果 |
| --- | --- |
| `",".join([])` | `""` |
| `",".join(["480"])` | `"480"` |
| `",".join(["480", "", "640"])` | `"480,,640"` |
| `"".join(["480", "640"])` | `"480640"` |
| `",".join(("480", "640"))` | `"480,640"` |

空字符串片段仍占据来源中的一个位置，`["480", "", "640"]` 有三个片段，因而有两个需要插入分隔符的间隔。分隔符自身则可以是空字符串，表示片段之间不加入其他内容；这与 `split("")` 的输入条件不同。

> [!IMPORTANT] 拼接的分隔位置与元素条件
> **`separator.join(source)` 按来源提供的顺序拼接字符串元素，只在相邻元素之间插入 `separator`，返回 `str`。**每个元素都必须已经是字符串，不会自动转换类型；非字符串元素会使调用引发 `TypeError`。空来源返回 `""`，只有一个元素时不加入分隔符。示例中的列表或元组自身不被修改。

列表中的整数即使能被 `print` 显示，也不能直接参与字符串拼接：

```python
parts = ["480", 640]
print(parts)
result = ",".join(parts)
print("after join")
```

第三行执行拼接时，第二个元素是整数，违反了元素必须是字符串的条件。此前已经输出：

```text
['480', 640]
```

异常末行为：

```text
TypeError: sequence item 1: expected str instance, int found
```

诊断中的 `item 1` 指索引一处的元素。调用没有返回，`result` 尚未绑定；来源列表仍为 `["480", 640]`，最后一行不会执行。

## 拆分与拼接保留了什么

拆分和拼接可以组合使用。默认空白拆分只保存片段，不保存原来每一段空白的种类、数量及首尾位置；再用一个空格拼接，会按这个分隔符重新安排间隔：

```python
text = " 480  640 "
parts = text.split()
result = " ".join(parts)

print(parts)
print(repr(result))
print(result == text)
print(repr(text))
```

输出为：

```text
['480', '640']
'480 640'
False
' 480  640 '
```

`result` 的两个片段之间只剩一个空格，首尾也没有空格，因而与 `text` 的内容不同。`repr` 让首尾空格在引号内可见，原文本的空白布局仍然保留在 `text` 中；[字符串不可变](07-string-length-indexing-and-slicing.md#字符串不可变与重新构造)，拆分和拼接都没有原地改写它。

> [!WARNING] 空白拆分不会保存原来的间隔
> **先用 `split()` 拆分，再用空格拼接，不保证恢复原文。**首尾空白、连续空白和不同种类的空白不会保存在片段列表中；`join` 只能插入指定的分隔符，不能从这些片段恢复已经丢失的间隔信息。
