# Python 全书结构

规划新章或调整分篇时读取。面向零编程经验，顺序理解优先；语言基础独立成立，以能跟上 AI 视觉课程、读用改写代码并独立查错为目标。视觉仅讲所需的 Python 工具基础，系统机器视觉与 AI 视觉另有知识主线；Agent 保留为兴趣分支。

语言基线为 Python 3.14，基础示例使用 CPython 3.14。主环境采用 CPython＋VS Code，以 `.py` 为主，视觉工具前补 Notebook；框架项目按依赖兼容性选版本。

## 阅读边界

00 章止于语言认识与运行入口，历史、命名和设计背景可充分展开。系统语言规则归入后续章节。

常见迭代消费与函数作为值先于依赖它们的数据处理；自定义协议另需类与方法。数组、张量的使用不以会实现类为前提；自定义 `Dataset`、`nn.Module` 另需类、继承及对应协议。工具篇按实际前置接入，无需等全部语言专题结束。

PyTorch 采用课程代码档，覆盖张量、数据批次、数据与模型接口、梯度及优化器基本调用；模型理论与训练方法归入 AI 视觉体系。Agent 与视觉共用 Python 基础，视觉工具不作为 Agent 的必读前置。工程内容按实际任务逐步补充和校正。
