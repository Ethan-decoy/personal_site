# Python 速查写作规范

新增或修改接口速查及其索引时使用，面向已经理解当前概念、需要按模块、类型或操作立即查用的读者。与[主线写作规范](writing-style.md)分工：主线建立模型，速查直接对应调用、作用、返回结果与成立条件。版本基线见 [book-structure.md](book-structure.md)，代码共同约定见 [coding-style.md](coding-style.md)。

## 条目表达

以“调用 → 作用／返回值；修改效果与必要条件”为基本关系，按内容选用紧凑表格、并列条目或短注释，不规定固定列数或字数。

- 保留实际 Python 调用形式及会改变用法的参数，输入对象与占位符在页首或附近定义。共同的导入、版本和前提可集中说明。
- 一条对应一个可查用操作；输入形式、返回形态或前提有实质差别时分开，语义相同的形式可并列。
- 返回值与修改效果分别交代。`None`、新对象、原对象、视图或迭代器等会影响后续操作的区别直接可见，“追加”“删除”等动词不能替代返回信息。
- 有效位置、缺失值、顺序、可修改性、惰性消费和失败条件就近保留；数组与张量按当前接口补足形状、轴、类型、设备、共享及梯度条件。
- 示例只用于消除调用歧义，以短调用、前后状态或带初始条件的片段为宜。解释与推演留在主线，必要时链接实际讲解小节。

## 页面组织与维护

按模块、类型或明确任务对象组织，调用名称直接出现在条目中，避免先列名称再重复展开相同内容。模块函数、对象方法、属性和运算符保持归属清楚；索引负责定位已有条目。

范围、版本与对应官方来源简短标注在页首或相关条目旁。修改时按相应版本逐项核对调用、效果、返回值和条件，确保压缩后仍可独立判断用法。片段验证与接入见 [authoring.md](authoring.md)。
